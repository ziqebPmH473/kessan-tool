# デザイン依頼：YouTube横動画のスライドのテンプレート（株価分析シリーズ「私が知らなかった実力株」）

作成日：2026-09-20（同日改訂）
依頼先：Claude Design
依頼者のツール：kessan-tool（株価分析の動画タブ → 横（YouTube））

---

## 1. 何を作るか

株価が大きく下落した銘柄を1社ずつ取り上げ、会社の事業と競争力を掘り下げるYouTube動画（約8分）のスライドの**テンプレート**です。
**表紙（オープニング）＋7章の計8枚**。中身は毎回、ツールが銘柄のデータを差し込みます。

- 動画は、スライド画像に2人の会話のナレーションを重ねて作ります。
- 動画編集ツール（ナレスラ）で、ナレーションに合わせて、スライドの一部へのズームや、四角枠・ハイライト・下線での強調を入れます。
- 株価の予想をする動画ではありません。主役は会社そのものです。

## 2. 目標の見た目と土台

添付の2種類の画像を使ってください（※依頼者が添付）。

1. **目標の見た目：ChatGPTで作ったスライド案8枚**（ユニオンツールの例）
   - 各章の構成・配置・部品（大見出し＋補足の一文、カード、アイコン、番号の丸、矢印の流れ図、大きな数字、左右の対比、下部の帯）はこの案に合わせてください。
   - **中身の文章・数字は仮のものです**（別の会社の内容が混ざっている箇所もあります）。テンプレートの形だけを見てください。
2. **土台：ツールの「スライド作成」タブの株価分析スライド6枚**
   - 配色・カード・チャート・フォントなどの見た目は、この土台と揃えてください（目標の案も、この土台をもとに作られています）。

土台の特徴：
- 背景は明るいグレー（#f8fafc）。上端に青のグラデーションの細い帯（#1d4ed8 → #0284c7）。
- 見出しは太字（色 #0f172a、weight 900）。白いカード（枠線 #e2e8f0、角丸 8px）。
- 意味で色を分けた薄い色付きのカード：青（#eff6ff／#2563eb）、緑（#f0fdf4／#059669）＝強み、赤（#fef2f2／#dc2626）＝弱み・リスク。
- 大きな数字（株価、変化率は赤）、ローソク足のチャート、右下に小さな署名「すみっこマネー大学/@sumikko_money」。
- フォント：Noto Sans JP（なければ Hiragino Sans／Yu Gothic／Meiryo）。

## 3. 条件

### 3-1. ズームと強調の使い方

- ずっとズームしているわけではありません。**全体表示が基本**で、話題によって一部にズームし、また全体に戻ります。
- 全体表示のまま、ナレスラの四角枠・ハイライト・下線で該当箇所を強調することもあります。下部の横長の帯などは、この使い方で見せます。
- ズームの範囲は画面と同じ16:9ですが、**ぴったり収める必要はありません**。隣の部分が少し映ってもかまいません。
- ツールが位置を測れるように、話題ごとのまとまり（カード1枚、帯1本など）の要素に `data-zone="名前"` を付けてください。

### 3-2. 描かないもの・空けておく場所

- **章のラベル・コーナー名は描かない**（ナレスラのコーナーテロップで右上に重ねます）。目標の案の右上にある「下落理由」などのラベル、ロゴ、「優れた企業をもっと身近に」は不要です。**右上（横73%〜100%、縦0〜15%くらい）は空けてください。**
- 右下の角：ロゴの透かしを重ねます。
- 左下の端（下から5%くらい）：資料の出典の表記を重ねることがあります。
- **出典はスライドに書きません**（ナレスラで資料の画像と出典の表記を差し込みます）。

### 3-3. 大きさ・文字

- 出力は 1920×1080（1280×720 で組んで1.5倍で画像化しても可）。
- 全体を表示したときも読める大きさ。文字数は毎回変わるので、各要素は高さに余裕のある作りにしてください（あふれるときはツールが文字を少し縮めます）。

### 3-4. 実装の制約（ツールが HTML を画像化するため）

- 出力は **HTML＋CSS**。JavaScriptは不要。
- 画像化には html2canvas を使います。次は使わないでください：`box-shadow`（角丸の内側が灰色に塗られる）、`background-clip:text`、`filter`、`backdrop-filter`、`mix-blend-mode`、外部の画像・アイコンフォント（アイコンはインラインSVG）。
- 差し込む箇所は `{{項目名}}` の目印に。繰り返す部分（カード3枚など）は、1つ分のHTMLを示してください。
- チャートとQRコードはツールが描きます：チャートは `<canvas data-chart></canvas>`（親要素いっぱい）、QRは `<div data-qr></div>`（約130×130px）。
- アイコンは、項目ごとに差し替えられるようにしてください（使うアイコンの一覧をSVGで）。

## 4. データ

### 4-1. ツールが持っている株価・会社の基本データ

| 項目 | 例 |
|---|---|
| 銘柄名／証券コード | サンプル精機／0000 |
| 事業の説明（1行） | プリント基板用の極細ドリルで世界シェア首位の精密工具メーカー |
| 現在株価と日付 | 4,850円（2026年9月18日） |
| 変化率と起点 | -40.9%（2026年5月の高値から） |
| 指標 | 予想PER／実績PBR／配当利回り／時価総額／52週レンジ |
| チャート | 週足のローソク足と出来高（約1年分） |
| 方向 | 下落（まれに上昇。上昇のときは「下落」を「上昇」に読み替える） |
| note記事のURL | QRコードにする |

### 4-2. 毎回の中身の文言

中身の文言はChatGPTに作らせます。**必要な項目は、このテンプレートに合わせて決めます。**
各スライドで差し込む項目（`{{...}}`）の一覧と、それぞれの目安の字数・個数を、テンプレートと一緒に示してください。
それをもとに、ChatGPTに出させるデータの形式をツール側で作ります。

### 4-3. スライドに載せないもの

株価の予想や水準（下値・目標株価・将来の株価・上昇余地）、株価シナリオとその確率、割安／割高の水準、売買を勧める表現。

## 5. 各スライド（目標の案との対応）

| # | スライド | 目標の案 | 補足 |
|---|---|---|---|
| 0 | 表紙（オープニング） | シリーズ名・銘柄名・キャッチ・株価カード・チャート・3つの問い | ①と内容が重なるので、役割を分けてよい（例：表紙は問いを見せ、①は注目点を見せる） |
| 1 | ① なぜ今この銘柄？ | 株価カード・チャート・今回の注目点3つ・今回の問い | |
| 2 | ② そもそも何の会社？ | 主力事業3つ・どこで稼ぐ？（4段の流れ）・この会社の特徴3つ | |
| 3 | ③ なぜ株価が下がった？ | 株価カード・要約・要因3枚・株価に効いた流れ（5段） | 要因の種類（業績の悪化／期待の剥落／評価の修正）で色を分けたい |
| 4 | ④ この会社の強みは何？ | 競争優位3つ・数字で見る強さ3つ・なぜ強いのか3つ | |
| 5 | ⑤ その強みは本物なのか？ | 強さの根拠3つ（緑）と崩れる条件3つ（赤）・見るべき証拠3つ | |
| 6 | ⑥ 今後どこを見る？ | 確認する指標4つ・今回のまとめ | |
| 7 | ⑦ まとめ | 結論3つ・押さえたい3点・続きはnote（項目＋QR） | |

## 6. 納品してほしいもの

1. 8枚分のテンプレート（HTML＋CSS）。差し込み箇所は `{{項目名}}`、話題のまとまりに `data-zone`。
2. 差し込む項目の一覧（スライドごと：項目名・目安の字数・個数・任意かどうか）。
3. 項目の数が変わるときの扱い（例：強みが2つ／4つのとき）。
4. サンプルデータを入れた状態の見た目。サンプルの中身は下の付録か、目標の案の文言を使ってください（正しさは問いません）。
