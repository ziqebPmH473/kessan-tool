# デザイン依頼：YouTube横動画のスライド（株価分析シリーズ「私が知らなかった実力株」）

作成日：2026-09-20（改訂）
依頼先：Claude Design

## 1. どんな動画か

- 株価が大きく下落した銘柄を1社ずつ取り上げ、会社の事業と競争力を掘り下げるYouTube動画（約8分）。
- 株価の予想をする動画ではない。主役は会社そのもの。
- スライド画像に、2人の会話のナレーションを重ねて作る。
- 動画編集ツールで、話に合わせてスライドの一部にズームしたり、四角枠などの印で強調したりする。

## 2. 作るスライド（表紙＋7章の8枚、1920×1080）

| # | スライド | 伝えること |
|---|---|---|
| 0 | 表紙 | どの銘柄の回か、株価がどれだけ下がったか、この動画で何を調べるか |
| 1 | なぜ今この銘柄？ | 株価がいつの高値からどれだけ下落したか、今の位置、この会社を調べる理由 |
| 2 | そもそも何の会社？ | 何を作り何で稼いでいるか、主要製品・主な顧客・市場、売上の構成 |
| 3 | なぜ株価が下がった？ | 下落の主な要因（3つ程度）と、それが業績の悪化・期待の剥落・評価の修正のどれにあたるか |
| 4 | この会社の強みは何？ | 競争力の理由（シェア、技術、顧客が乗り換えにくい理由など）と、それを示す数字 |
| 5 | その強みは本物なのか？ | 強い点と、強みが崩れる条件（事業のリスク）の対比 |
| 6 | 今後どこを見る？ | 事業が強いままかを確かめるために見る指標（3〜4つ） |
| 7 | まとめ | 要点3〜4つ、株価の分析はnoteで扱っていることの案内（QRコード） |

## 3. 使えるデータ

**株価・会社の基本データ（ツールが持っている）**
- 銘柄名、証券コード、事業の説明（1行）
- 現在株価と日付、変化率と起点（例：-40.9%、2026年5月の高値から）
- 指標：予想PER、実績PBR、配当利回り、時価総額、52週レンジ
- 週足のチャート（約1年分）
- note記事のURL

**各章の文言（毎回ChatGPTが作る）**
- 各章の内容（表の「伝えること」）について、見出し・短い説明・数字をChatGPTに作らせる。
- 項目の形（何個・何字）はデザインに合わせて決めるので、デザイン案と一緒に「このスライドにはこの項目が要る」を示してほしい。

## 4. 前提

- ズームは画面と同じ16:9の範囲で寄る。ずっとズームするわけではなく、全体表示のまま印で強調する場面もある。スライドは1枚として完成していることを優先する。
- 右上には動画編集ツールで章のタイトルを重ねるので空けておく。右下にはロゴの透かしが入る。
- 出典はスライドに書かない（動画編集ツールで差し込む）。
- 株価の予想・水準（下値、目標株価、上昇余地）、株価シナリオ、割安・割高の水準、売買を勧める表現は載せない。
- 最終的にはツールがHTMLに銘柄ごとのデータを差し込んで画像にする。
- 参考：ツールで今使っている株価分析スライド（6枚）の画像を添付する（※依頼者が添付）。
