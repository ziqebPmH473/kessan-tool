# デザイン依頼：YouTube横動画のスライド（株価分析シリーズ「私が知らなかった実力株」）

作成日：2026-09-20（改訂）
依頼先：Claude Design

## 1. 動画

- 既存の「株価分析レポート」を起点に、株価が大きく下落した銘柄を、会社そのものを深掘りして紹介するYouTube動画（約8分）。
- 中心テーマは「株価は大きく下落している。しかし、この会社の事業や競争力を調べると面白い。なぜ強いのか、何が弱点なのか、今後どこを見るべきなのか」。
- 株価予想の動画にはしない。

## 2. 作るスライド

表紙＋7章。各章にベースとなるスライドを1枚作り、毎回同じレイアウト体系を使う。

### 表紙
- プレゼンの最初のページ（サムネイルとは別）。

### スライド1「なぜ今この銘柄？」
- 銘柄名
- 株価下落率
- 高値
- 現在株価
- 株価チャート
- 短い問題提起

### スライド2「何の会社？」
- 主力事業
- 主要製品
- 顧客
- 売上構造
- 簡単な事業フロー

### スライド3「なぜ株価が下がった？」
- 下落要因を3〜4個に整理
- 例：決算 → 市場期待 → バリュエーション → 株価下落

### スライド4「この会社の強み」
- 2〜4項目
- 例：市場シェア・技術力・顧客基盤・高収益性

### スライド5「その強みは本物？」
- 左右比較形式が基本
- 左：強み
- 右：弱点／崩れる条件

### スライド6「今後どこを見る？」
- 3〜5個の事業KPI
- 具体的な株価水準は載せない

### スライド7「まとめ」
- 3〜4点
- note導線を小さく表示してもよい

## 3. データ

- 株価分析レポートの無料部分（株価の値動き、下落要因、企業の強み・弱み など）
- レポートで不足する部分を公開情報（企業IR、決算説明資料、有価証券報告書、中期経営計画、企業公式サイト、業界団体・官公庁の一次資料、信頼できる報道）から追加調査したもの（ChatGPTが作成）
- 株価データ（現在株価、高値、下落率、期間、週足チャート、PER・PBR・配当利回り・時価総額などの指標）
- 株価分析レポートの有料部分（下値、12か月後の株価シナリオ、確率、割安水準、株価の転換条件など）は使わない

## 4. 前提

- 動画編集ツール（ナレスラ）で、ナレーションに合わせてスライドの一部へのズーム、枠・ハイライトなどでの強調、根拠資料（出典）の画像の差し込み、コーナーテロップを入れる。
- 画面は16:9で、ズームも16:9。
- ズームするので、情報量は多くてよい。
- スライドの章ラベルは不要（コーナーテロップで入れる）。
- 出典はスライドに書かない（動画編集ツールで差し込む）。
- ツールの「スライド作成」タブで使っている株価分析スライド（添付）を基に作る。
