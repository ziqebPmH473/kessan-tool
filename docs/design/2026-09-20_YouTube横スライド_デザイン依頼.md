# デザイン依頼：YouTube横動画のスライド（株価分析シリーズ「私が知らなかった実力株」）

作成日：2026-09-20
依頼先：Claude Design
依頼者のツール：kessan-tool（株価分析の動画タブ → 横（YouTube））

---

## 1. 何を作るか

株価が大きく下落した銘柄を1社ずつ取り上げ、会社の事業と競争力を掘り下げるYouTube動画（6〜10分）のスライドです。
**表紙＋7章の計8枚**のテンプレートを作ってください。中身はツールが毎回、銘柄のデータを差し込みます。

- 動画は、スライド画像に2人の会話の音声（ナレーション）を重ねて作ります。
- 動画編集ツール（ナレスラ）で、ナレーションに合わせてスライドの一部に**ズーム**し、話している箇所を大きく見せます。
- **株価の予想をする動画ではありません。** 主役は会社そのものです（何の会社か／なぜ下がったか／なぜ強いか／強さは続くか／今後何を見るか）。

## 2. デザインの土台

ツールの「スライド作成」タブで作っている株価分析スライド（6枚、1280×720）のデザインを土台にしてください。**まったく新しいデザインにはしないでください。**
（添付：スライド作成タブの6枚の画像。※依頼者が添付）

土台の特徴：

- 背景は明るいグレー（#f8fafc）。上端に青のグラデーションの細い帯（#1d4ed8 → #0284c7）。
- 見出しは左上に太字（色 #0f172a、weight 900）。
- 白いカード（枠線 #e2e8f0、角丸 8px）。
- 意味で色を分けた薄い色付きのカード。左端に太めの色線を付ける。
  - 青（#eff6ff／線 #2563eb）：なぜ下落しているのか
  - 緑（#f0fdf4／線 #059669）：強み
  - 赤（#fef2f2／線 #dc2626）：弱み・リスク
- 大きな数字（株価 4,850円、変化率 -40.9% を赤）。
- 指標の一覧（ラベル左・値右の行）、ローソク足のチャート、横棒のゲージ、色の点つきの行、左右2列のまとめ。
- 右下に小さな署名「すみっこマネー大学/@sumikko_money」。
- フォント：Noto Sans JP（なければ Hiragino Sans／Yu Gothic／Meiryo）。

## 3. 必ず守る条件

### 3-1. ズーム（いちばん重要）

- ズームの範囲は、**画面と同じ16:9に固定**です。縦長・横長の範囲にはズームできません。
- ナレーションで1つの話題を話している間、その話題の**まとまり（カード1枚など）にズーム**します。
- そのため、**ズームで見せる話題のまとまりは、それ自体を16:9に近い形にしてください**。
  - 悪い例：画面の横幅いっぱいの細長い行（16:9に広げるとほぼ全体になり、拡大されない）。縦に細長い列（隣の列も映ってしまう）。
  - 良い例：画面を2×2に分けた1マス（16:9）。16:9のカードの中に見出し・数字・説明がまとまっている。
- まとまりの大きさは、画面の1/4〜1/2程度（拡大率が約2〜4倍になる）。
- 連続する話題のまとまりは、隣り合わせに置いてください（ズームしたまま隣へ移動して見せるため）。
- ズームで見せるまとまりの要素には、`data-zone="名前"` を付けてください。ツールが描画後にその位置を測り、ズームの範囲を計算します。

### 3-2. 画面の中で空けておく場所（動画編集ツールが上に重ねる）

- **右上**（横 73%〜100%、縦 0〜15% くらい）：章のタイトル（コーナーテロップ）を重ねます。文字を置かないでください。
- **右下の角**：ロゴの透かしを重ねます。
- **左下の端**（下から5%くらい）：資料の出典の表記を重ねることがあります。大事な文字を置かないでください。
- **出典はスライドに書きません**（動画編集ツールで、資料の画像と出典の表記を差し込むため）。

### 3-3. 大きさ・文字

- 出力は **1920×1080**（ツールは 1280×720 で組んで1.5倍で画像化しています。どちらの基準で作ってもかまいません）。
- 全体を表示したときも読めること。本文は 1920×1080 基準で**おおむね28px以上**（1280×720基準で19px以上）。
- 情報量は多くてよい（ズームで読ませるため）。ただし「ただ4つに割っただけ」「文字を並べただけ」にはせず、土台のスライドと同じく1枚の資料として完成した見た目にしてください。
- 文字数は毎回変わります。あふれる場合はツールが文字を少しずつ縮めるので、各要素は**高さに余裕のある作り**にしてください。

### 3-4. 実装の制約（ツールが HTML を画像化するため）

- 出力は **HTML＋CSS**（1枚ずつ、または共通CSS＋8枚分のHTML）。JavaScriptは不要。
- 画像化には html2canvas を使います。次は使わないでください（正しく描かれないため）：
  - `box-shadow`（角丸の内側が灰色に塗られる）
  - `background-clip:text`、`filter`、`backdrop-filter`、`mix-blend-mode`
  - 外部の画像・アイコンフォント（アイコンが必要ならインラインSVG）
- 差し込む箇所は `{{name}}` のような目印にしてください（ツールが置き換えます）。
- チャートとQRコードはツールが描きます。置く場所に次の要素を置いてください。
  - チャート：`<canvas data-chart></canvas>`（親要素の大きさいっぱいに描かれる）
  - QRコード：`<div data-qr></div>`（約130×130px）

## 4. 使えるデータ

### 4-1. 株価・会社の基本データ（ツールが持っている）

| 項目 | 例 |
|---|---|
| 銘柄名／証券コード／読みがな | サンプル精機／0000／さんぷるせいき |
| 事業の説明（1行） | プリント基板用の極細ドリルで世界シェア首位の精密工具メーカー |
| 現在株価 | 4,850円 |
| 変化率と起点 | -40.9%（2026年5月の高値から） |
| 指標 | 予想PER 18.2倍／実績PBR 2.1倍／配当利回り 2.4%／時価総額 2,450億円／52週レンジ 4,700〜8,300円 |
| チャート | 週足のローソク足と出来高（約1年分） |
| 方向 | 下落（まれに上昇。上昇のときは「下落」を「上昇」に読み替える） |
| note記事のURL | QRコードにする |

### 4-2. ChatGPTが作るスライド用の文言（毎回の中身）

字数は目安です。`**語**` は強調（色を変える）です。

| 章 | 項目 |
|---|---|
| 共通 | `title` スライドの見出し（22字以内）／`corner` 右上のコーナー名（8字以内、動画編集ツールで重ねる） |
| 表紙 | `catch` キャッチコピー（22字以内） |
| ① なぜ今この銘柄？ | `items` 下落の背景×3（見出し12字／説明40字）／`questions` この動画で確かめること×3（各25字） |
| ② そもそも何の会社？ | `desc` 何をしている会社か（70字）／`items` 主要製品・主な顧客・強い市場など×3（見出し10字／説明50字）／`mix` 売上構成（事業名と比率%、2〜5個、無い場合もある） |
| ③ なぜ株価が下がった？ | `items` 要因×3（`tag` 種類＝「業績の悪化」「期待の剥落」「評価の修正」のどれか／見出し16字／説明50字）／`summary` 整理の1文（45字） |
| ④ この会社の強みは何？ | `items` 強み×3〜4（見出し14字／`num` 強みを示す数字や語 8字・任意／`numLabel` その説明 10字・任意／説明55字） |
| ⑤ その強みは本物なのか？ | `strong` 強い点×3（見出し14字／説明45字）／`risk` 強みが崩れる条件×3（見出し14字／説明45字） |
| ⑥ 今後どこを見る？ | `items` 確認する事業の指標×3〜4（見出し12字／`now` 直近の値・任意／`why` なぜ見るか40字／`sign` 強さが続いていると言える状態30字） |
| ⑦ まとめ | `points` まとめ×3〜4（各40字） |

固定の文言：
- シリーズ名「私が知らなかった実力株」（表紙）
- 章名：①なぜ今この銘柄？ ②そもそも何の会社？ ③なぜ株価が下がった？ ④この会社の強みは何？ ⑤その強みは本物なのか？ ⑥今後どこを見る？ ⑦まとめ
- ⑦のnote案内：「株価の下値や12か月後のシナリオ、バリュエーションはnoteで詳しく分析しています。」＋ 項目「3〜9か月の下値シナリオ／12か月後の3シナリオ／株価以外の転換点のモノサシ／リスクとシナリオが崩れる条件」＋ QRコード

### 4-3. スライドに載せてはいけないもの

株価の予想や水準（下値・目標株価・将来の株価・上昇余地）、株価シナリオとその確率、割安／割高の水準、売買を勧める表現。これらは有料のnote記事で扱います。

## 5. 各スライドの内容とズームの順番

ズームの順番は、ナレーションで話す順番です。各章で「全体 → まとまり1 → まとまり2 → …」と進みます。

| # | スライド | 載せるもの | ズームで見せるまとまり（16:9に近い形で） |
|---|---|---|---|
| 0 | 表紙 | シリーズ名、銘柄名＋コード、キャッチ、株価と変化率、チャート | なし（全体のみ） |
| 1 | ① なぜ今この銘柄？ | 株価・変化率・起点、指標5つ、チャート、下落の背景3つ、この動画で確かめること3つ | 株価と指標 → チャート → 下落の背景 → 確かめること |
| 2 | ② そもそも何の会社？ | 銘柄名、事業の説明、主要製品・顧客・市場の3項目、売上構成（ゲージ） | 事業の説明 → 項目1 → 項目2 → 項目3 → 売上構成 |
| 3 | ③ なぜ株価が下がった？ | 要因3つ（種類で色分け：業績の悪化＝赤、期待の剥落＝青、評価の修正＝グレー）、整理の1文 | 要因1 → 要因2 → 要因3 → 整理 |
| 4 | ④ この会社の強みは何？ | 強み3〜4つ（緑、数字があれば大きく） | 強み1 → 強み2 → 強み3（→ 強み4） |
| 5 | ⑤ その強みは本物なのか？ | 強い点3つ（緑）と崩れる条件3つ（赤）を対比 | 強い点1と崩れる条件1 → 2の組 → 3の組（対になるものを同じまとまりで見せたい） |
| 6 | ⑥ 今後どこを見る？ | 確認する指標3〜4つ（名前、直近の値、なぜ見るか、続くサイン） | 指標1 → 指標2 → 指標3（→ 指標4） |
| 7 | ⑦ まとめ | まとめ3〜4点、note案内とQR | まとめ1〜4 → note |

## 6. 納品してほしいもの

1. 8枚分の HTML＋CSS（1920×1080 または 1280×720）。差し込み箇所は `{{項目名}}`、ズームのまとまりに `data-zone`。
2. 項目の数が変わるときの扱い（例：④の強みが3つのとき・4つのとき、②の売上構成が無いとき）。
3. サンプルデータを入れた状態の見た目（下の例をそのまま使ってください）。
