# 設計メモ：横動画の SNS 投稿文（X・YouTubeの投稿・Instagram・Lemon8・TikTok）

作成：2026-09-21　Notion：KT-1「投稿文を YouTube・他SNSの分も作る」

## 位置づけ

- 横動画を作る回は縦動画を作らない。横の「投稿文」タブが、縦動画側の Instagram・TikTok 投稿文の代わりになる（縦の側は触らない）。
- 目的は YouTube の総再生時間。どのSNSにも**スライドは載せない**（中身を先に見せると本来の再生が減る）。
- 添付：Instagram・Lemon8・TikTok は**縦のサムネ（3:4・1080×1440）1枚**（別タスク）。YouTubeの投稿は、投稿の種類で「動画」を選び、この動画を選ぶ（ファイルの添付ではない）。
- note の宣伝は5つ全部に入れる。note が売れれば収益になる。

## 作り方

- X も同じ枠。Gem 原文の「X投稿案」の目的・内容・禁止を5つすべてに当てはめる。
- 構成がぶれないように、**AIは部品だけを書き、ツールが組み立てる**。
  - 部品：`hook`（5つ共通の1行目の問いかけ・銘柄名入り・30字以内）、`points`（この動画で確かめること・章の順に3〜5個・答えは書かない）、`x`（Xの続き1〜2文）、`lemon8_title`、`lemon8_intro`、SNSごとのタグ。
  - 組み立て：
    - X：【#銘柄名（コード）】／hook／x／x_tags／YouTubeのURL（最終行）
    - YouTubeの投稿・Instagram：hook／この動画で確かめること・points／定型文／タグ
    - Lemon8：見出し＝【#銘柄名（コード）】＋lemon8_title（注目してもらいたい点）。本文＝lemon8_intro／この動画で確かめること ①〜／定型文／タグ
    - TikTok：hook・points／定型文／タグ
- 誘導と note の案内は**定型文**（設定タブで直せる。`{下値/上値}` は株価の向きで入れ替え）。AIには書かせない。
- タグ：X・YouTubeの投稿は概要欄と同じ（汎用的な言葉は使わない。Xは銘柄名・コードを入れない）。Instagram 5個・Lemon8 5個・TikTok 5〜8個は、分野の言葉（株式投資の分野を探す人が使う言葉）も入れる。

## 各SNSのプロフィールのリンク（定型文の前提）

| SNS | プロフィールのリンク | 定型文の誘導 |
|---|---|---|
| Instagram | note・YouTube・X | 動画は YouTube、分析は note（どちらもプロフィールから） |
| Lemon8 | TikTok・note | **note だけ**（あえて YouTube は置かない。note の記事に動画を貼っている） |
| TikTok | Lemon8 だけ（YouTube を置く項目は無い） | YouTube で「すみっこマネー大学」と検索。note は案内だけ |
| YouTubeの投稿 | — | note は「リンクは動画の概要欄に」 |

## note の記事と動画

- 動画は note の無料部分の最後に貼っている。有料部分で何が分かるかは、先頭に切り出して書いていない。
- 動画の最後で「下値・シナリオは note で」と言わせているので、note の中で見た人にはすぐ下が有料の区切りになる（買うまでの距離が短い）。
- 埋め込みの再生も YouTube の再生回数・総再生時間に数えられる。
