# 横動画のオープニング・エンディング（2026-09-23）

Notion：「YT動画 オープニング（要点）とエンディング（観点）をナレスラの書き出しに入れる」（KT-46）。
株価分析の横動画と YT動画の両方に効く（画面・関数は共用）。

## ねらい

- オープニング（OP）：見る人のため。「この動画を見ると何が分かるか」を要点3つで見せる。
- エンディング（ED）：収益化のため（繰り返しの多いコンテンツ対策）。「なぜこの動画を作ったか・どうするつもりか」という、作り手の観点を入れる。
- 声は入れない（Gemini の音声）。動く背景は加工済みの素材を使い回す。ナレスラでは編集しない（ナレスラは編集ソフトではない）。

## 流れと置き場所

| 作業 | 必要なもの | 置く場所 |
|---|---|---|
| 素材（背景の動画）の登録 | ― | 設定タブ（全PJ共通） |
| OP・ED の区分を選ぶ | ― | 新タブ「OP・ED」（PJごと） |
| 文の案を出す・直す・音声を作る | 章の構成、本編の文字起こし、動画資料 | 新タブ「OP・ED」（「音声」と「スライド」の間） |
| OP の位置を決める | スライドの切り替え | 「演出」。割り当てと一緒に AI が選び、手で直せる |
| 書き出し | 全部 | 「演出」の書き出し（`ynExport`） |

## 区分

- OP・ED の区分：テーマ／ニュース／決算。PJごとに選ぶ。初めの値は、株価分析＝決算、YT動画＝テーマ。
- 背景の素材を選ぶのに使う。

## 素材（背景の動画）

- OP 用：区分ごとに数本（3本くらい）。書き出すときに、その区分の中からランダムに1本。60秒くらいの長さでもらう（OP の後ろの前振りの区間も流すため）。
- ED 用：区分ごとに1本（`Documents/動画編集/10_音源等/映像素材/エンディング` の3本を、スロー・ぼかし済みにしたもの）。
- 設定タブで登録する。保存は KTStore の `_common`（ナレスラのひな形と同じ。全PJ共通）。元はサーバー（R2）、使う作業をした端末にだけ取ってきて置く（今の mediaNs の動きのまま）。
- 注意：`/api/media` の PUT はサーバーで本文を全部読み込んでから R2 に入れる。数十MB（base64 でさらに約1.3倍）でも上限（100MB）には収まる見込みだが、送れなければ、そのまま流して入れる形に直す。

## 文の案（AI）

どちらも案を3つ出し、選んでから手で直す。

- **OP**：「この動画を見ると何が分かるか」の要点3つ。要点ごとに
  - 画面に出す文：短くまとめたもの
  - 音声で読む文：少しくわしく話すもの（前置きの一言を含めてよい）
  - もと：章の構成、本編の文字起こし
- **ED**：なぜこの動画を作ったか・どうするつもりか。
  - 決算（株価分析）：株価が下がっていたから／名前しか聞いたことがなかった・くわしく知らなかった、の方向
  - テーマ・ニュース：最近のニュースや、近いうちにある予定とつなげる。直近に何があったか・何があるかを**検索して**関連付ける
  - もと：動画資料、本編の文字起こし、検索の結果
- 検索：今の `/api/analyze` には検索が無い。Gemini の Google 検索（`tools: [{google_search:{}}]`）を、ED の案のときだけ使えるように足す。

## 音声

- OP・ED それぞれ1本で作る（`/api/tts`。声・モデルは今の横動画の既定に合わせる）。
- OP の②③の文字を出す時刻は、作った音声を文字起こし（`/api/transcribe`）して取る。
- ED の字幕の時刻も、同じく文字起こしから取る。

## 演出（OP の位置）

- OP の動画は「スライドの1枚」として、演出のスライドの並びに入れる。
  - 始まり：本編の「1. 本当の導入（問題提起・何を話すか）」と「2. 次への前振り」の境目。割り当ての AI が選び、違えば手で直す（今の切り替えと同じ操作）。
  - 終わり：次のスライド（1つ目の章）の切り替え。
- 画面：音声の表示に OP の音声を入れた状態で見せ、その区間の背景の色を変える。
- ED は本編の最後のあと。演出の並びの最後に置く。

## 書き出し（`ynExport` に足す）

1. **音声を作り直す**：本編の音声を OP の位置で切り、「前・無音・OP・無音・後・無音・ED」をつないで **WAV** で書き出す（形が違う音声をつなぐため、いったん元の音に戻す。WAV なら音質は変わらない。12分で約60MB）。
2. **時刻をずらす**：OP の位置より後ろの、切り替え・ズーム・強調・字幕・カット・出典・チャートの時刻に、OP の分（無音＋OP＋無音）を足す。
3. **OP の動画**：`kind:'video'`・解説を止めない（`narMute:false`）スライド。動画の音は取り除く。
   - 長さ＝OP の始まりから次の切り替えまで。**カットで消える区間があれば、その分を引いた長さ**（ナレスラの動画はカットに関係なく自分の長さで流れるため）。
   - 素材の先頭から、その長さで切る（後ろを捨てるだけなので再エンコードしない。動画を扱うライブラリを CDN から読む。PDF と同じ読み方）。
   - 切ったあとに長さを読み取り、必要な長さと合うか確かめる（1コマ以内）。合わない・素材が短いときは、書き出しを止めて知らせる。
4. **OP の文字**：画面に出す文①②③を、ナレスラの文字の描画（出典の表記と同じ `type:'text'`）で順に出す。出し始めは文字起こしの時刻、終わりは OP の動画の終わり。OP の区間には下の字幕を入れない。
5. **ED**：本編の最後のあとに、ED の動画のスライド（長さ＝ED の音声＋前後の無音）。ED の文は下の字幕（`manualSubtitles`）で出す。画面の上の方は空ける（YouTube の終了画面用）。

## 作る順番（区切りごとにコミット）

1. 設定：素材の登録（全PJ共通）
2. 新タブ「OP・ED」：区分・案（AI、ED は検索あり）・直す欄・音声・文字起こし
3. 演出：OP の位置（AI が選ぶ・手で直す）、音声の表示
4. 書き出し：音声のつなぎ（WAV）・時刻のずらし・動画を切る・長さの確認・文字と字幕

## 作るときに確かめること

- ナレスラで、解説を止めない動画のスライドと、切り替えの時刻（`switchPoints`）の関係（動画スライドは切り替えを使わず自分の長さで終わる。前後の画像スライドの切り替えがずれないか）。
- カットと動画の長さ（上の 3.）。
- 数十MBの動画を `/api/media` に送れるか。
