# 共通設定（⚙）（2026-09-25）

上の段の「⚙ 共通設定」（削除の右）に、PJ ごとではない設定をまとめた。変えるとすぐ保存され、すべての PJ に効く。

## 置いたもの
| 欄 | 保存先 | 前は |
|---|---|---|
| 株価分析のサムネ3段目の初期値（新規PJはこれで始まる・自動で入らないとき） | `kt-common` の `th3` | `updateThumbText` の固定文字 |
| 台本の声・声のモデル（縦動画・決算動画） | `kt-common` の `tts-voice` `tts-model` → `vd-*`/`ev-*` | PJ ごと |
| 縦動画の文章モデル | `model` → `vd-model` `ev-model` | PJ ごと |
| 横動画の Gemini のモデル（作業ごと） | `yt-m-*` | PJ ごと |
| 固定タグ・note案内文 | `fixed-tags` `xnote` | PJ ごと |
| 概要欄の定型文 | `yt-p-fixed` | PJ ごと |
| SNSの定型文（株価分析／YT動画で別） | `yt-f-<k>@stock` / `@gen` | PJ ごと（種類ごとの初期値） |
| スライドの色・書体、OP・EDの背景動画・テロップ・声、BGM | 今までどおり（`kt-slide-style` など・KT_YN `_common`） | 横動画の設定タブ・音声タブ |

## 作り
- `kt-common`（localStorage）を正にし、KTStore の `LS_SYNC` に足してサーバーの shared の行にも入れる。
- PJ ごとだった欄は、元の場所に隠して残す（`.kg-hide`。関数が id で読むため）。`tabIoElements` で `kgIsCommon(id)` を外すので、PJ の保存・読み込み・新規の初期化には入らない。
- `kgApply()` が共通設定の値を元の欄へ入れる：起動時、PJ を開いたあと（`ktOpen`）、種類を切り替えたあと（`ytSetCtx`。SNSの定型文が種類ごとのため）。`kt-common` にまだ無い値は、そのときの欄の値を最初の値にする（今の PJ の設定を引き継ぐ）。
- 前から全体共通だった欄（id なし・data 属性）は、HTML をこの画面へ移しただけ。
- サムネを前の PJ から引き継ぐ変更（75991e0）は取り消した（8f31ee5）。AI で入るサムネは初期値不要、株価分析の3段目だけ初期値を持つ。

## 気をつけること
- 各 PJ の行には、前に保存した声・定型文などの値が残っている（読み込み時に使わないだけ）。
- 設定を増やすときは、`KG_ITEMS` と `kgIsCommon` の両方に足す。
