# 実装記録：据え置きの通期予想が出ない／出典を AI が落とす／貸借対照表の外ラベルが注記と重なる

作業日：2026-10-14
対象：`index.html`（ff276bf）、`assets/kessan-viz.js`（6ee03f8 ＝ visualizer 9f84b16）
きっかけ：津田駒工業（6217）2026年11月期 第3四半期の PJ。本番 D1 の json を読んで原因を確認した。

## 1. 据え置きなのに通期予想の数字が出ない（1枚画像・分析動画）

- AI の出力が `status=据え置き, col1_header=通期予想, col2_header=-, sales_1=360億円, sales_2=-` のように、数字を1列目に入れて2列目を「-」にしていた。
- 表示側は据え置きのとき「1列目を隠して2列目を通期予想として出す」作り（画像：`renderImage` の GUIDANCE 描画、動画：`evVizExtras` → `forecast_revision`）。かみ合わず空になった。
- 直し：据え置き（据置・変更なし・修正なし）で2列目が空（空・-・---・—）なら1列目の数字を使う。動画側は before/after 両方に同じ値を入れる（予想スライドは据え置きだと after を1本の棒で出す）。2列目の見出しが「-」なら1列目の見出し、無ければ「通期予想」。
- プロンプトは足していない（受け取り側で吸収）。動画は開くたびに `KV.build(analysis, evVizExtras())` で作り直すので、古い PJ にも効く。

## 2. 「資産合計 に出典（資料名・ページ）がありません」

- 数字（266億円）はあるが `source` が無い。`MetricSchema.source` が `nullable().optional()` で、AI に渡す JSON Schema の必須キーに入っておらず、落とされることがあった。
- 直し（visualizer）：`source` を必須キー（nullable、説明に「reported/estimated なら必ず入れる。calculated のときだけ null」）に。`normalize` で無いときは null に。ダミーデータにも `source: null`。
- 警告文を「○○：数字はありますが、出典（どの資料の何ページか）を AI が取れていません。資料で確認してください」に。
- 注意：必須キーにしても AI が落とす可能性はゼロではない。警告は残してある。

## 3. 貸借対照表で細い棒の外ラベルが注記と重なる

- 細い棒（高さ 54px 未満）のラベルは棒の中心の高さで列の外に出す。強調の注記は重ならないよう下へずらして積む（`calloutTop`）が、外ラベルを消す判定（`nearEmph`）は棒の中心同士の距離（130px）しか見ておらず、ずらした注記と重なった。
- 直し（`BalanceSheetScene.tsx`）：外ラベルを消す条件を「その棒自身が強調されている（注記に同じ名前と金額が出る）」または「同じ側の注記の実際の範囲（calloutTop〜＋128/160px）と高さが重なる」に。
- ローカルで 6217 のデータを入れて 0:54 で確認：外ラベルが消え、注記と重ならない。

- `node --check`：index.html の script 2本 pass。visualizer `npm run build` pass → `npm run to-tool`。
- ローカル（wrangler pages dev）で 6217 の input-data と ev-viz-json を入れ、画像の通期予想 360億円/5億円/1億円、動画の forecast_compare も同じ値、警告文の新しい文言を確認。
