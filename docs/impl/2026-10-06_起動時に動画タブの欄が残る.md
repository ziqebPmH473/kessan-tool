# 起動時に、動画タブの欄だけ前のPJの内容が残る（2026-10-06）

## 症状

株価分析が「新規」の状態で起動したとき（新しいタブで開いたとき・PJを消したあとなど）、
スライド作成の欄は空なのに、🎬 動画タブを開くとリンク確認の結果・note URL・台本・資料欄などに前のPJの内容が入っている。消す手段もない。

## 原因

- 動画タブの欄は、画面を組み立てるとき（`vdInit` → `vdRestoreFields(P)` / `ytRestoreFields()`）に localStorage（`kessanTool:v1`）から値を入れている。
  これは `KTStore.ready()` より前に走るので、「前に開いていた画面」の値が入る。
- そのあと `restoreState()` は、サーバーの行から作り直した state にある欄だけを上書きする。
  新規（行が無い）種別の欄は state に無いので上書きされず、前の値が残る。
- スライド作成の欄は `vdInit` で入れていないので空のまま。だから「新規に見えるのに動画タブだけ残る」。

## 直し方

`window.onload`（index.html）で、サーバー保存のときは `restoreState()` の前に全種別を `ktResetKindFields()` で空に戻し、
そのあと `restoreState()` で行のある種別だけ入れ直す。終わったら `saveStateNow()` で localStorage も画面に合わせる。

- 行のある種別は `restoreState()` で元どおり入る（確認済み）。
- 行の無い種別は空のまま。行は触るまで作らない（`KTStore.touch` の仕組みはそのまま）。
- ブラウザ保存（サーバー無し）のときは localStorage が唯一の保存先なので、戻さない。

## 確認

ローカルの `wrangler pages dev --d1 --r2`（サーバー保存）で、PJを保存 → その行をAPIで消す → 新しいタブで起動、で再現し、修正後に動画タブの欄が空になること、
既存PJ（株価分析・YT動画）を開いているタブの再読み込みで中身が戻ることを確認した。

## 残り

- 新規にしたとき、サムネ文言の欄が HTML の見本（「最高値から40％下落：ユニチカ：…」）に戻る。縦スライド・サムネのプレビューに見本がそのまま出る（別件）。

## 追記（同日）

欄を空に戻しても、リンク確認の結果（YL）は画面を組み立てたときに古い欄から読んだものがメモリに残り、YT動画の出典リンク一覧に前のPJのものが出ていた。起動時の戻しのあとに `ytLinkLoad()` と `ytRenderLinks()` で戻した欄から読み直すようにした。
