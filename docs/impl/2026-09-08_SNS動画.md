# 実装記録：SNS動画（縦型）機能・note記事の注意喚起・投稿文のURL差し込み

作業日：2026-09-07 〜 2026-09-08

コミット：a6c3190 〜 f37990c（main、Cloudflare Pages へ自動デプロイ）

## 目的

- note の有料記事（株価分析）への導線として、X／TikTok／Instagram に無料範囲だけの縦動画を投稿する。
- 決算分析も同じ仕組みで縦動画にする（こちらは note 誘導なしの認知型）。
- 動画はスライドを流しっぱなし＋ナレーション（テロップなし）。台本はスライド単位で音声化し、1本に結合する。

## 実装内容

### 共通（動画モジュール、`vd`=株価分析／`ev`=決算分析）
- 動画タブの中は「スライド・投稿」「台本・音声」「設定」の3タブ。生成カードはボタンのみ。
- 設定：QR用URL（vdのみ）、文章モデル、枚数（evのみ）、チャート期間、声・音声モデル、透かしロゴの濃さ。TTS設定と透かし度は両タブで同期し localStorage に保存（次回も同じ）。
- 台本ボックスはスライド数ぶん。文字数／目安秒（7文字/秒）を各ボックスと合計で表示。
- 音声：`/api/tts`（Gemini TTS）でスライド単位に生成し IndexedDB に保持。標準プレーヤーで再生・単品DL。「結合して再生」「音声出力」で無音の間を挟んで結合→こもり補正→MP3/WAV。結合時に「スライド切替タイミング」を出力。補正・間・形式は結合時のみ適用。
- 縦スライド 1080×1920：サムネ（黒地3段・中央寄せ）＋本編。透かしロゴは中央、図形の前・文字の後ろ（z-index）。免責は最終スライド下部の固定文。ステップ表示（①株価推移など）は無し。ZIPは `コード_銘柄名_0_サムネ`、`_1_…` ＋ 台本.txt ＋ 切替タイミング。
- チャート：AIには株探データの全期間を渡し、描画時に期間欄で絞る（AIを通さず描き直し）。株価分析は日足→週足変換。一番左の月ラベルは出さず、月は数字のみ。期間ラベルは「直近○ヶ月／直近1年3ヶ月」形式。
- 投稿文：X／Instagram／TikTok。X は1行目【】固定、記事URL欄＋「貼付け」「URLを差し込み」で【】の直下にURL。「▼ …はnoteで」が最終行（vd）。

### 株価分析（vd）
- 5枚：①株価推移（チャート拡大）／②理由／③強み／④弱み（各「結論＋短い補足」×3）／⑤まとめ＋note誘導（QR）。
- ⑤の下落幅は「2026年5月高値から -48.9%」のように基準を表示。note の分析項目は固定文（下落／上昇で読み替え）。
- 台本⑤の案内は固定文「株価の底値、12か月後の株価シナリオ、株価以外の転換点のモノサシ、そしてリスクについては、noteで詳しく分析しています」（上昇は「天井」）。
- サムネ文言は「サムネイル」タブのテキストを流用（AI生成しない）。
- プロンプト：スライド文言を先に出力させ、台本はその語句・順番に従う指示（台本とスライドのずれ対策）。

### 決算分析（ev）
- 左ペインを「決算分析／動画」サブタブ化。動画タブで右ペインも縦スライドに切り替わる。
- 3枚（予想修正なし）／4枚（修正前後の数値あり）を整形データの GUIDANCE から自動判定（据え置き・数値なしは3枚）。手動切替可。
- 数値（実績・前年比・修正前後・進捗率・株価前後）は整形データから直接描き、文言（結論・理由・注目点・焦点）と台本・投稿文だけ AI 生成。実績スライドに業績予想を混ぜない指示あり。
- 「整形後に動画も自動生成」チェック（出力データ作成ボタンの下）。
- サムネ文言は整形データから組む（今回の評価：社名：修正の有無）。
- 音声ファイル名：`決算分析_コード_銘柄名.mp3`（株価分析は `株価分析_…`）。

### note記事（記事・SNSタブ）
- 導入末尾に固定の注意書き1文、記事末尾に「まとめ」「ご注意」画像の挿入目印（2枚連続）。
- 全スライドZIPに `assets/disclaimer_note.png` を `99_ご注意` として同梱。
- 投稿文を X（URLは最終行）／YouTube（URLは【】行の直下）に分割。記事URL欄＋貼付け／差し替え。

## 判断事項

- サムネ文言・note分析項目・台本⑤の案内文は AI に作らせず固定／流用（ぶれ防止）。
- 動画スライドの数値はデータから直接描く（転記ミス防止）。
- X（動画用）の URL 位置は【】の直下（「〜はnoteで」を最終行にするため）。記事タブの X は従来どおり最終行。
- 透かしロゴはサムネも中央・同じ濃さ（黒地ではほぼ見えない）。
