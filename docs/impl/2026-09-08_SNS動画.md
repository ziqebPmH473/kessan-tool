# 実装記録：SNS動画（縦型）機能・note記事の注意喚起・投稿文のURL差し込み

作業日：2026-09-07 〜 2026-09-08

コミット：a6c3190 〜 f37990c（main、Cloudflare Pages へ自動デプロイ）

## 目的

- note の有料記事（株価分析）への導線として、X／TikTok／Instagram に無料範囲だけの縦動画を投稿する。
- 決算分析も同じ仕組みで縦動画にする（こちらは note 誘導なしの認知型）。
- 動画はスライドを流しっぱなし＋ナレーション（テロップなし）。台本はスライド単位で音声化し、1本に結合する。

## 実装内容

### 共通（動画モジュール、`vd`=株価分析／`ev`=決算分析）
- 動画タブの中は「スライド・投稿」「台本・音声」「設定」の3タブ。生成カードはボタンのみ。
- 設定：QR用URL（vdのみ）、文章モデル、枚数（evのみ）、チャート期間、声・音声モデル、透かしロゴの濃さ。TTS設定と透かし度は両タブで同期し localStorage に保存（次回も同じ）。
- 台本ボックスはスライド数ぶん。文字数／目安秒（7文字/秒）を各ボックスと合計で表示。
- 音声：`/api/tts`（Gemini TTS）でスライド単位に生成し IndexedDB に保持。標準プレーヤーで再生・単品DL。「結合して再生」「音声出力」で無音の間を挟んで結合→こもり補正→MP3/WAV。結合時に「スライド切替タイミング」を出力。補正・間・形式は結合時のみ適用。
- 縦スライド 1080×1920：サムネ（黒地3段・中央寄せ）＋本編。透かしロゴは中央、図形の前・文字の後ろ（z-index）。免責は最終スライド下部の固定文。ステップ表示（①株価推移など）は無し。ZIPは `コード_銘柄名_0_サムネ`、`_1_…` ＋ 台本.txt ＋ 切替タイミング。
- チャート：AIには株探データの全期間を渡し、描画時に期間欄で絞る（AIを通さず描き直し）。株価分析は日足→週足変換。一番左の月ラベルは出さず、月は数字のみ。期間ラベルは「直近○ヶ月／直近1年3ヶ月」形式。
- 投稿文：X／Instagram／TikTok。X は1行目【】固定、記事URL欄＋「貼付け」「URLを差し込み」で【】の直下にURL。「▼ …はnoteで」が最終行（vd）。

### 株価分析（vd）
- 5枚：①株価推移（チャート拡大）／②理由／③強み／④弱み（各「結論＋短い補足」×3）／⑤まとめ＋note誘導（QR）。
- ⑤の下落幅は「2026年5月高値から -48.9%」のように基準を表示。note の分析項目は固定文（下落／上昇で読み替え）。
- 台本⑤の案内は固定文「株価の底値、12か月後の株価シナリオ、株価以外の転換点のモノサシ、そしてリスクについては、noteで詳しく分析しています」（上昇は「天井」）。
- サムネ文言は「サムネイル」タブのテキストを流用（AI生成しない）。
- プロンプト：スライド文言を先に出力させ、台本はその語句・順番に従う指示（台本とスライドのずれ対策）。

### 決算分析（ev）
- 左ペインを「決算分析／動画」サブタブ化。動画タブで右ペインも縦スライドに切り替わる。
- 3枚（予想修正なし）／4枚（修正前後の数値あり）を整形データの GUIDANCE から自動判定（据え置き・数値なしは3枚）。手動切替可。
- 数値（実績・前年比・修正前後・進捗率・株価前後）は整形データから直接描き、文言（結論・理由・注目点・焦点）と台本・投稿文だけ AI 生成。実績スライドに業績予想を混ぜない指示あり。
- 「整形後に動画も自動生成」チェック（出力データ作成ボタンの下）。
- サムネ文言は整形データから組む（今回の評価：社名：修正の有無）。
- 音声ファイル名：`決算分析_コード_銘柄名.mp3`（株価分析は `株価分析_…`）。

### note記事（記事・SNSタブ）
- 導入末尾に固定の注意書き1文、記事末尾に「まとめ」「ご注意」画像の挿入目印（2枚連続）。
- 全スライドZIPに `assets/disclaimer_note.png` を `99_ご注意` として同梱。
- 投稿文を X（URLは最終行）／YouTube（URLは【】行の直下）に分割。記事URL欄＋貼付け／差し替え。

## 追記：株価分析のX投稿文を「返信用」に変更（2026-09-10）

### 背景
- Xで動画にURLを入れてもリンクカードが出ず、本文中のテキストリンクになるためクリックが取れていなかった。
- note告知（リンクカードあり）を本体ポストにし、その返信として動画を投稿する運用に変更する。

### 変更点（`index.html`）
- 株価分析のX投稿文はツールで組み立てる（AIに作らせない）。構成は4行：
  1. `{銘柄名}の株価が{期間・変動}{下がった/上がった}理由、現状、強みと弱みは動画にまとめました。`
  2. `[V5]`の「問い」（無ければ方向に応じた既定文）
  3. note案内文（設定タブで変更可。既定「その答えはnoteで分析しています。」）
  4. ハッシュタグ（AI生成＋固定タグ）
- 銘柄名・期間・変動・方向は株価分析タブの入力欄から取るため、AIの出力ぶれがない。
- プロンプトの7番は【X用ハッシュタグ】だけに縮小（#銘柄名 #証券コードを先頭に4〜6個、汎用タグ禁止）。
- 140文字を超える場合は、AIが付けた業種・テーマのタグを後ろから削る（銘柄名・コードと固定タグは残す）。
- 動画タブの「記事URL」欄と「URLを差し込み」ボタンを廃止（返信ポストにURLは入れない）。記事・SNSタブ側のURL差し込みは従来どおり。
- 決算分析（ev）は変更なし。

### 判断事項
- 2行目の問いはスライド⑤と揃えるため`[V5]`から取る。長い場合はそのまま出し、出力後に手で調整する。
- 動画のサムネは変更しない（X・Instagramで同じ動画を使うため、分けると動画を2本作る必要がある）。
- TikTokは株価分析の投稿を停止し、決算分析のみとする（詐欺行為の自動検知でバンされたため）。

## 追記：決算分析動画の台本とスライドの数値ずれ・通期予想スライドの修正（2026-09-12）

### 背景（ユーザー報告）
- 台本①でスライド②の実績の数字を先に話していた（スライド①は概要だけで数字の表は無い）。
- 通期予想スライドが右端で切れていた。会社予想がレンジ開示だと「レンジ下限 → レンジ上限」を修正前→修正後の表として描いていた。

### 変更点（`index.html`）
- AIに渡す基本情報に【各スライドに表示される数値】（`evSlideNumbersText`）を追加。台本の数値はそのスライドに表示される数値だけ、という厳守ルールをプロンプトに追加。
- 台本①：売上・利益の金額や前年比、通期予想の数値を言わない指示に変更。台本②：細かい数字はここで話す。台本③：レンジ予想は「〇〇億〜〇〇億円の見通し」と幅で話す。
- スライド③：列を「項目｜中央（修正前→修正後 or 下限〜上限）｜修正率・進捗」の3列に変更し、中央は文字幅を測って文字サイズを自動調整。レンジは `476.1〜488.2億円` の1値表示、見出しは「会社予想レンジ（下限〜上限）」。レンジで修正なしなら修正率は出さない。
- 金額を `476億1,300万円 → 476.1億円` に短縮（`evCompactYen`、スライド②③と台本用数値で共通）。
- 配当が 0円→0円 の行は出さない。本決算（今期実績→来期予想）は右列の小さい数字を「前年比」と表記。
- 枚数の自動判定は変更しない（業績予想があれば手動で4枚にして使う運用。ユーザー確認済み）。

- 台本欄は常に4つ（①全体像 ②実績 ③通期予想 ④市場反応）にし、3枚⇔4枚の切替では見出しと表示・非表示だけを変える（3枚は③を隠す）。`VD_CFG[P].slots()` が表示中の欄番号（3枚＝[1,2,4]）を返し、生成結果の書き込み・文字数・未生成を音声化・結合・切替タイミング・台本.txt は表示中の欄だけを処理する。以前は欄を枚数ぶん作り直して番号のまま残していたため、見出しと台本が食い違っていた（一時的に中身を移動する実装にしたが、ユーザー提案の表示切替方式に変更）。
- 注意：変更前に3枚で保存していたデータは、市場反応の台本が③欄（隠れる側）に入っている。生成し直せば正しく入る。

### 確認
- ローカルで合成データ（レンジ予想・修正なし／上方修正・1兆円台の値）を描画し、表のはみ出しが無いこと、プロンプト文言が入ることを確認。AI生成結果は本番で要確認。
