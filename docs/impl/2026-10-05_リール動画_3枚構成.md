# リール動画を3枚構成に（2026-10-05）

## なにを

SNSタブの「リール動画」（Instagram の見出しのボタン）で作る mp4 を、縦のサムネ1枚（7秒・寄るだけ）から、次の3枚に変えた。

| 順 | 中身 | 秒数（既定） |
|---|---|---|
| 1 | 縦のサムネ（サムネイルタブの文）。ゆっくり寄る | 3 |
| 2 | YouTube誘導：「なぜ／下がった？」「下落理由を▶YouTubeで解説」＋YouTubeのURLのQR＋「YouTubeで見る」 | 3.5 |
| 3 | note誘導：「下値余地と／12ヶ月後を分析」「もっと詳しい分析は note で」＋noteのURLのQR＋「noteで読む」 | 4.5 |

切り替えは 0.4 秒のフェード（終わりの0.4秒に次の1枚を重ねていく）。QRの2枚は止めたまま。合計 11 秒・1080×1920・音なし（BGMはインスタのアプリで付ける）。

ChatGPT との相談（サムネ3秒 → 無料のYouTube 3.5秒 → 有料のnote 4.5秒、QRは1画面に1つ、アニメは控えめ）に沿った。えらび図鑑（affiri-console/assets/reel-qr.js）と同じく、Instagram・TikTok の UI がかぶる上12%・下20%には中身を置かない（y 230〜1520 に収める）。

## どう作ったか（index.html）

- QRスライドの HTML は `buildReelQr(brand,url)`（`.vqr`、CSS は `.vth-cta` の次）。見出しは `reelT1Html`（`*…*` がその色、「｜」で行を分ける、いちばん長い行が幅に収まる大きさ）、説明は `reelT2Html`（「YouTube」「note」の文字をロゴ付きに）。
- 文言と秒数は ⚙ 共通設定の「リール動画（Instagram・TikTok）」（`KG_ITEMS` の `g:'reel'`、キー `reel-yt1/yt2/nt1/nt2/secs`）。`{下がった/上がった}` の書き方で株価の向き（`getDir()`）により左右を入れ替える（`reelDirText`）。
- 画像化は既存の `renderVideoToBlob` に `sel`（描く要素のセレクタ）を足して使う。QR は `vFillDynamic` の `[data-qr]` で描く。大きさは `data-qr-size` で変えられるようにした（いままで 218 固定）。
- URL は SNSタブの「YouTubeのURL」（`p-yturl`）と `ytNoteUrl()`。無いときは確認してそのスライドを外す。両方無ければサムネだけ7秒（前と同じ）。
- 動画は `downloadThumbReel` で mediabunny（avc / 60fps）。`seg`（各スライドの開始・終了時刻）を作り、1コマごとに「いまのスライド」＋「終わりの0.4秒なら次のスライドをα重ね」で描く。

## 気づいた点（ユーザーへ伝えた）

- 見本の「すみっこマネー大学」の下の英字は入れていない。
- 上昇の銘柄では「なぜ上がった？」「上昇理由を」「上値余地と」に自動で変わる。
- 見本の下のボタン（y≈1700）は Instagram・TikTok の UI にかぶる位置なので、y 1392〜1508 に上げた。
- YouTube のURLは動画を上げたあとでないと入らないので、リールは YouTube 公開後に作る前提。

## 確認したこと

- ローカルで、2枚のQRスライドの見た目（赤／緑、2行の見出し、ロゴ、QR、ボタン）と、mp4 が 11 秒・1080×1920 で書き出せること。共通設定に5つの欄が出ること。
