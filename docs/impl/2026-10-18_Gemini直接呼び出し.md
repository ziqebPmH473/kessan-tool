# Gemini を画面から直接呼ぶ（2026-10-18）

## 起きていたこと
- 量の多い作業（入力約1万トークン）で、3.8 Flash が毎回「HTTP 524 応答がJSONではありません: error code: 524」（約125秒）で失敗し、下のモデルへ降格していた。3.7 も同じことがあった。
- 524 は Cloudflare の時間切れ。Pages Function（/api/analyze）から Google への呼び出しで、最初の返事が約125秒までに来ないと切られる。設定では延ばせない。
- 少しずつ受け取る形（streamGenerateContent＋includeThoughts、c728c15）にしても、3.8 は125秒までに最初の1文字も返さず、同じく切られた。
- 画面 → Pages Function の間は4分以上でも切れていない。

## したこと
- `functions/api/gemini-key.js`：APIキー（環境変数 GEMINI_API_KEY のまま）を画面に渡す。本番のURL（Access のログイン済み＝Cf-Access-Jwt-Assertion あり）と localhost だけ。デプロイごとの別URLには渡さない。
- `index.html` の `aiFetch()`：`fetch('/api/analyze',…)` と同じ呼び方・同じ返し方で、画面から Google に直接頼む。組み立て（資料・添付・検索・URL読み・JSON）と下のモデルへの切り替えは analyze.js と同じ。キーはメモリにだけ持ち、URL には載せず `x-goog-api-key` ヘッダーで渡す。キーを受け取れないときは /api/analyze へ。
- 呼び出し10か所を `aiFetch` に置き換え。

## 気にしておくこと
- analyze.js を直すときは aiFetch も同じように直す（2か所にある）。
- キーはサーバーの外（ログインした本人のブラウザ）に出るようになった。了承済み。
