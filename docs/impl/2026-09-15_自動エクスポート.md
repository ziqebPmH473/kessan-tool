# 実装記録：処理完了時の自動エクスポートとファイル名の日時先頭化

作業日：2026-09-15
対象：`index.html`
コミット：d0a9d6c, b33fd48（main、Cloudflare Pages へ自動デプロイ）

## 目的

- 決算分析・株価分析の処理が終わったところで、手動の「📤 エクスポート」を押さなくてもタブ内容（裏データ含む）のJSONが保存されるようにする。
- エクスポートJSONのファイル名を日時が先頭になる形式にして、フォルダで日付順に並ぶようにする。

## 実装内容

- 決算分析：「📤 出力データ作成」（`geminiFormatEarn`）が成功して完了ステータスを出した直後に `exportTabData('earnings')` を呼ぶ。動画素材の自動生成（チェックON時）が終わった後に書き出される。
- 株価分析：「📝 記事・SNSを生成」（`geminiArticle`）が成功して完了ステータスを出した直後に `exportTabData('price')` を呼ぶ。「2.」の下のボタン（`geminiArticleFromMake`）経由でも同じ関数を通る。
- どちらも Gemini がエラーの場合は途中で return するためエクスポートされない。`try/catch` で囲み、エクスポート失敗が本体処理に影響しないようにした。
- `tabIoFileName`：`{タブ名}_{コード}_{銘柄名}_{YYYYMMDD_HHMM}.json` → `{YYYYMMDD_HHMM}_{タブ名}_{コード}_{銘柄名}.json`。手動・自動エクスポート共通。インポート側はファイル名を見ないため旧形式もそのまま読める。

## 判断事項

- 個別銘柄分析タブの「出力データ作成」（`geminiFormatSa`）は指示に含まれていないため変更していない。
- 既存の `exportTabData` をそのまま呼ぶだけにし、書き出す内容・形式（`TAB_IO_FORMAT`）は変えていない。

## テスト・動作確認

- `<script>` ブロックの JS 構文チェック（node の `new Function`）のみ実施、pass。
- **未確認**：ブラウザでの実行（Gemini 呼び出し後にダウンロードが走ること、ファイル名）。本番のAPIキーが必要なためローカルでは実行していない。本番で1回実行して確認する。

## 残課題・次回
