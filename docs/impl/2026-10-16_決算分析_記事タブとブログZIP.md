# 決算分析：📝 記事タブ（note・ブログ）、ブログ用 ZIP、YouTube ショートのタイトル・概要欄（2026-10-16）

Notion（📊 決算ツールPJタスク）：
- 決算分析に「📝 記事」タブ（note 記事・ブログ記事）を足す
- 決算の縦動画：YouTube ショート用のタイトルと概要欄を出す
- 決算分析：ブログ用 ZIP（記事.txt・アイキャッチ・分析動画の MP4・各スライドの画像）を保存する

## 何を作ったか

### 📝 記事タブ（`#earn-tab-article`、関数は `ea*`。本体スクリプトの末尾、決算まとめの `dgCopy` の手前）

- 決算分析の4つ目のサブタブ。`switchEarnTab('article')`。右ペインは1枚画像のまま（`earnPrevMode('image')`）。
- 元は「1.」の FC レポート（`fc-report`）と「2.」の整形済みデータ（`input-data`）。どちらかがあれば作れる。
- note 記事（表なし。最初の段落のあとに注意書き `ygNoteDisclaimer`、関連記事 `relAuto(REL_EA)`）とブログ記事（表あり。【要点】3行つき）。
  - 作りは YT動画タブの記事（`ygArticlePrompt` / `ygArtApply`）をそのまま写した。プロンプトは `eaArticlePrompt(k)`、反映は `eaArtApply(k,text)`。
  - API（`eaArtAi`）／💬 プロンプト（`eaCopyPrompt`）／📋 貼り付け（`eaArtPaste`）の3経路。売買表現チェックは `artComplianceCheck` に欄を渡す（`eaArtCheck`）。
  - 【要点】は `parseArticleOutput` が知らないので `eaParsePoints` で拾う。
- 欄：`ea-yt-url`（ブログの【YouTube】）、`ea-note-url`（ブログの【note】。決算まとめの QR もこの欄を見る。前は `art-url` を見ていたが決算 PJ には無い欄だった）、`ea-model`、`ea-n-*`、`ea-b-*`、`ea-zip-video`、`ea-check`、`ea-rel-*`。すべて `#mode-earnings` の中なので TAB_IO 経由で PJ と一緒に保存される。

### ブログ用 ZIP（`eaBlogZip`。sumikko-money の `docs/article-zip.md` の形）

```
<コード>_<社名>_記事.zip
├─ 記事.txt            【タイトル】【カテゴリ】決算分析【銘柄コード】【要点】【本　文】【ハッシュタグ】【note】【YouTube】（空のブロックは書かない）
├─ アイキャッチ.jpg     分析動画の横サムネ（右の画面「サムネ」の文から evThImage('h')）
├─ 画像/01_<場面名>.png  本文の [ここに「場面名」のスライド画像を挿入] の順。分析動画の各場面の、動きが終わったコマ
└─ 動画/01_<社名>_分析動画.mp4  ブラウザで書き出し（読み上げ・BGM は分析動画の保存先 evVizAudioStore から）。圧縮しない（STORE）
```

- 画像の枠：ブログのプロンプトに、分析動画の場面（`KessanViz.scenes`、サムネの場面は除く）を「この行をそのまま入れる」と渡す。ZIP を作るとき、本文の枠を上から順に見て場面名が一致するものだけ残し、一致しない行は外して知らせる。枠の数と画像の枚数が必ずそろう。
- 動画の行 `[ここに「<社名>の決算を図解した分析動画」の動画を挿入]` は AI に書かせず、反映時にリード文の終わり（最初の `##` の手前）へツールが入れる（`eaVideoApply`）。「分析動画（MP4）も入れる」を外すと行も外す。
- MP4 の書き出しは数分かかり、タブを隠すと一時停止する（部品の作り）。状態は `ea-zip-status` に出す。

### kessan-visualizer 側（`src/embed/headless.tsx`、visualizer のコミットは kessan-tool のコミット文に書く）

画面（EmbedPanel）を持たずに書き出す入口を足した。`npm run to-tool` で `assets/kessan-viz.js` に入る。

- `KessanViz.scenes(viz, settings)` → `[{id, title}]`（動画に出る場面だけ。`resolveScenes`）
- `KessanViz.scenePngs({visualization, settings, ids?, onProgress})` → `[{id, title, blob}]`。画面外に本寸の Player を置き、各場面の「終わりのフェードの手前」のコマを html-to-image で PNG に
- `KessanViz.exportMp4({visualization, settings, audioStore, onProgress, signal})` → MP4 の Blob。`Mp4ExportButton` と同じ `exportMp4` を呼ぶ。音声は `useProjectAudio` と同じ決まり（台本の文が一致する読み上げだけ）で audioStore から集める

### YouTube ショート用のタイトル・概要欄（🎬 動画タブ・決算側）

- `videoPromptEv` に【YouTubeタイトル】【YouTube概要欄】の2ブロックを足した（nBlocks 8/9 → 10/11）。API の回数は増えない。
- `parseVideoOutput(text,nScripts,P)` に P を足し、`P==='ev'` のときだけ2つの見出しを拾う（株価分析の縦動画はブロック数が変わらないので、フォールバックの「コードブロック数＝見出し数」が壊れない）。
- 欄 `ev-ytt`（1行）・`ev-ytd`（固定タグを末尾に）。`vdPersistIds` に追加。

## 追記（同日）note とブログを1回で作る

すみぽん：「note もブログも一括で作れないの？（API も1回で）。手動もまとめて」。Notion：「決算分析の記事：note とブログを1回で作る（API 1回・手動もまとめて）」。

- ボタンを上の欄にまとめた：「🤖 note・ブログをまとめて作る」（`eaArtAi(btn)`）、手動の「💬 プロンプト」（`eaCopyPrompt(btn)`）「📋 貼り付け」（`eaArtPaste()`）。note・ブログの欄ごとの作るボタンは外した。
- プロンプト `eaArticlePrompt()` は1つ。共通の書き方 →【noteだけの決まり】（表なし）→【ブログだけの決まり】（表・タイトルの形・要点・画像の枠）。出力は `===== note =====` と `===== ブログ =====` の2つに分けさせる。
- `eaSplitBoth(text)` で分ける（区切りの行が無いときは、2つ目の【タイトル】から後ろをブログとみなす）。それぞれは今までの `eaArtApply('n'|'b', …)` で欄に入れる。片方しか取れなかったときは、取れた方だけ入れて知らせる。
- API で作ったときは、続けて売買表現チェックを note・ブログの順に1回ずつ（2回）と、note の関連記事。記事を作る呼び出しは2回 → 1回になった。
- 確かめたこと：ローカルで、プロンプトに区切り・note の決まり・画像の枠が入ること、見本の出力（区切りあり／なし）を貼って note とブログの欄に分かれて入ること（note は注意書き、ブログは表・要点・画像の枠）。Gemini での出力は未確認。

## 追記（同日）GO(581A) の ZIP を見ての直し

すみぽんが作った `581A_GO_記事.zip` を見て4点。3（画像が本文とずれる）は v20261016-1707 で直し済み。
- 見出しが全部 `###`：`eaArtApply` で、本文に `##` が無く `###` だけなら `##` に上げる（v20261016-1715）。
- 「だ・である」が混ざる：売買表現チェック（`ART_CHECK_PROMPT`）の書き直し例8つの文末を「です・ます」に（v20261016-1715）。株価分析・YT動画の記事も同じチェックを使うが、どれも「です・ます」なので問題ない。
- 前年同期比が 0.1pt ずれる（営業利益 +92.8% と +92.9%）：本番の PJ（p:earnings:20261015-235539-h9h8）を D1 で読むと、前年の営業利益は説明資料 p.36 の 1,577（百万円）で、3,042/1,577 を計算すると +92.9%。資料は丸めた前年の値から計算していないので、資料の記載と食い違う。visualizer（コミット下記）で、主要項目に `yoy_pct_reported`（資料に書かれている前年同期比）を足し、あればそれを表示に使う（手で数字を直したときは直した値から計算）。**作り直した PJ から効く**（GO の既存データには入っていない）。
