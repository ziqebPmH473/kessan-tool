# 出典のリンク確認：525 を「開けない」にしない（2026-10-01）

## なにが起きたか
- `ssl4.eir-parts.net` のPDF（適時開示）が、ブラウザでは開けるのに、リンク確認では「開けません（525）」の赤になった。

## なぜ
- リンク確認は `/api/grab?check=1` が Cloudflare Pages Functions の `fetch` でそのURLを開く。
- 520〜526 は Cloudflare が「相手のサイトにつなげなかった」ときに返す番号（525＝暗号化通信の握手に失敗）。
  ページが無いのではなく、ツールのサーバーとそのサイトの相性の問題。ブラウザは普通に開ける。

## どう直したか
- `index.html` の `ytLinkJudge()`：520〜526 を 403・429・503 と同じ「warn」にした。
  ツールからは開けなかった旨を出し、リンクを目で確かめて「確認した」を押せるようにした。
- `functions/api/grab.js` は変えていない。

## まだ残っていること
- 同じサイトのPDFを「撮る」（`/api/grab` 本体）も同じ理由で失敗するはず。必要なら画面を撮った画像で代用する。
