## やったこと

本番の D1 から、決算PJ（kind=earnings）の分析動画 JSON（`fields.ev-viz-json`）99件を読み、部品で表せない場面・データの形を数えた。
そのうえで部品を足し・直し、分析 JSON から材料（ShortData）を作る変換を書いて、99件すべてに当てた（数字が壊れる件は0）。

## 決めたこと・理由

- 材料は分析 JSON から機械的に作る（`fromAnalysis.ts`）。AI には、その会社で**使える部品だけ**を渡す（条件は `availability.ts`）。使えない部品を選ばせない。
- 配当は「（株式分割前）」「（中間）」のような注記つき、2.2倍超・半分未満の変化は出さない。保存データで、サンリオ 69円（分割前）→16円（分割後）、三井不動産 18.5円（中間）→37円（年間）のように、くらべ方が揃っていないものがあった。
- 5つの評価の呼び名は、やさしい言い方に（財務健全性 → 財務の安全性、キャッシュ創出力 → お金を生む力）。
- 「営業利益から純利益まで」は、本業と最後の利益で向きや黒字・赤字が食い違うときだけ使う（同じ向きなら決算ハイライトで足りる）。
- 事業ごとの利益で「その他」「調整額」は注目の事業にしない。
- 新しい部品も、これまでの指摘に合わせた：白地・カメラはほぼ固定・強調は色・比べるものは同じ尺度・マイナスは0の線の下。

## 気づいたが直していないこと（データ側）

- 業績の推移の数字が怪しい件がある（パナソニックの 26/3 の営業利益 2,364億円、津田駒工業で 26/11 の実績と予想が両方ある など）。推移は株探の取得値なので、部品ではなく取得の側の話。
- 会社予想の修正は、据え置き（変化なし）でも部品が使える扱い（78件）。据え置きは「進み具合」とあわせて見せる方が意味があるので、AI への指示で調整する。

## 後半：横の分析動画も3Dの部品で出す（同じ日）

すみぽんの意図は「いまの分析動画（横）も新方式（3D）で出せるようにし、その部品を超ショートでも使う」。前半はショートの目だけで見ていたので、いまの分析動画の13場面（kessan-visualizer の `src/remotion/scenes/`）と突き合わせ直した。AI は使わない。

| いまの場面 | 3Dの部品 | 足した・直したこと |
|---|---|---|
| 表紙 | CoverPart（新） | 社名・決算期・札・見出し・「このあと」 |
| 決算ハイライト | Kpi3D | 横は左の列に札・見出し・今回の注目 |
| 四半期単独 | quarter | — |
| 株価の推移 | stock | 分析動画では取れた期間すべて（超ショートは発表前の40日） |
| 業績予想の比較 | revision → progress → dividend | 修正の理由を出す。修正前後が無ければ forecast |
| 損益の構造 | pl → margin →（食い違うときだけ）netgap | その他の収益・費用を段に入れる（33件） |
| 業績の推移 | trend | — |
| 貸借対照表 | bs | 内訳（現金・売掛金・在庫・固定資産／買掛金・有利子負債・その他負債／純資産）が前期末の高さから今期末へ動く |
| キャッシュフロー | cf | 換算差額など（その他）を段に入れる（59件） |
| セグメント | segments → segprofit | 横は一覧を左の列に |
| 注目ポイント | points | 「8.9% → 9.9%（+1.0pt）」の前後の数字。横は GOOD と WATCH を左右に |
| 総括 | ratings → ConclusionPart（新） | 強み・特徴・確認点・次回確認 |

- 縦横の切り替え：`Titles`・`Legend`・`Scene3D`（`parts.tsx`）。横は3Dを画面いっぱいに描き、カメラの写る範囲を右へずらして左に文字の列を空ける（3Dの枠の境目が出ないように）。
- 横の組み立て：`Video.tsx`（場面の順と秒数は SCENE_DEFAULTS と同じ。部品が2つ以上の場面はつづけて出す）。
- 超ショートの組み立て：`autoPlan.ts`。主役は「赤字転落・黒字転換 → 営業と純利益の食い違い → 予想の修正 → 株価±10% → 進み具合が目安から15ポイント以上 → 事業ごとの利益 → 推移 → 利益率 → 損益の構造」の順で、使える最初のもの。さらっとは株価＋配当などから1つ。まとめ3行は総括（札・強み・次回確認）。字幕は出さない。
- 確認：架空の2社と実データ4社で静止画、パナソニックで横の分析動画と超ショートを通しで書き出した（書き出しはプロジェクトの外。コミットしない）。
