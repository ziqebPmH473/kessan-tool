# 「🧩 決算まとめ」タブ（作成済みの分析動画を選んで並べ、冒頭と最後を付けて1本に）（2026-10-16）

Notion: 「「🧩 決算まとめ」タブ（作成済みの分析動画を選んで並べ、冒頭と最後を付けて1本にする）」「まとめ動画：概要欄（銘柄ごとの開始時間つきの目次・noteの案内）を自動で作る」（📊 決算ツールPJタスク）。
部品は別リポジトリ `C:\work\kessan-visualizer`（`src/remotion/DigestMain.tsx`・`src/embed/DigestPanel.tsx`）。

## 何を作ったか

- 一番上の種別に **🧩 決算まとめ**（kind `digest`）を足した。1 PJ ＝ 1 日分のまとめ。個別の銘柄の画面（決算分析タブ）には入れない（すみぽん 2026-10-16：「個別の動画じゃないんだから」）。
- 左 `#mode-digest`：決算分析の PJ の一覧（チェックで入れる・▲▼で並び）、部品の操作部（`#dg-controls`：日付・冒頭と最後の文・読み上げ・BGM・区切り・MP4 書き出し）、概要欄。右 `#capture-area-digest`：プレビュー（`KessanViz.digest.mount`）。
- 欄（PJ に保存。`TAB_IO.digest`）：`dg-date`・`dg-title`（一覧の名前。「10/15 決算まとめ（A・B）」を自動で入れる）・`dg-ids`（選んだ決算 PJ の id を並び順で JSON）・`dg-settings`（部品の設定 JSON）・`dg-note-url`・`dg-desc`（概要欄）・`dg-yt-title`（タイトル案）。
- 選んだ PJ の中身は **開かずに読む**：欄は `KTStore.fetchDocs(ids)`（`ev-viz-json`・`ev-viz-settings`・`art-url`・`p-name`）、読み上げ音声は `KT_TTS.getFor(pid, 'ev:viz:nar:<scene>')`（store.js の mediaNs に足した。端末内 → サーバーの順。書き込みはしない）。文が音声と違うものは使わない（分析動画と同じ）。
- 動画データは、抽出データ（analysis）があれば `KV.build` で最新の描き方にし、株価の推移・業績予想（その PJ の欄から足す extras）は保存済みの visualization のものを戻す。
- 冒頭・最後の読み上げは `KT_TTS` の `dg:nar:intro` / `dg:nar:outro`（kindOf に `dg:` → `digest` を足した。まとめの PJ ごと）。BGM は分析動画と同じ共通の `bgm:viz`。声・速さも分析動画と同じ設定（`ev-tts-voice`・`viz-speed`）。
- 概要欄（`dgDescRender`）：説明 → note の案内と URL → 目次（00:00 は「オープニング・1銘柄目」。各銘柄の記事 URL があれば「▶ 記事：」を添える。最後に「noteのご案内」）→ 共通設定の定型文（`yt-p-fixed`）→ 注意事項 → タグ。開始秒は `KessanViz.digest.timeline()`。手で直した文は上書きしない（「🔄 作り直す」で作り直す）。
- 部品（visualizer）：`DigestMain`＝冒頭（日付・銘柄名のチップ・冒頭の文を1文字ずつ）→ 各銘柄の `Main` を `Sequence` で並べる（横・サムネ OFF・BGM OFF に整える `itemSettings`）→ 最後（note 案内）。BGM は全体で1本。書き出しは東証の動画と同じ `PlayerMp4Button`（読み上げの開始秒は `digestMixTimeline`）。Remotion Studio にも見本 `Digest` を登録した。

## なぜそうしたか

- 各銘柄の MP4 を書き出して別ソフトでつなぐのではなく、1 本として組むと、目次の秒数が正確に出て、個別のサムネを外すのも設定だけで済む。
- まとめの単位は PJ にした（共通設定ではなく）。過去のまとめを一覧から開き直せる。
- 種別の切り替えで `requestAnimationFrame` は使わない（裏のタブでは動かない。YT動画タブの記録と同じ）。

## 確認したこと（ローカル pages-db・見本データ2社）

- 一覧に決算 PJ が出て、チェック → 2 銘柄を読む → 区切り（00:00 / 00:06 / 01:22 / 02:39）・合計 02:46・概要欄・タイトル案が入る。並び替えで読み直す。
- 再読み込みで、まとめの PJ・選んだ銘柄・並びが戻る（起動時の種別の一覧に `digest` を足した）。右側に分析動画の画面が残らない。
- 冒頭・最後のコマ（`npx remotion still … Digest --frame=100 / -30`）は意図どおり。
- **確認できていないもの**：ブラウザでの MP4 書き出し。Claude のブラウザでは既存の分析動画の書き出しも「フレーム 0 の画像化が 20 秒以内に終わりませんでした」で止まる（環境の問題）ので、本番の Chrome で要確認。読み上げ音声つき（冒頭・最後・各銘柄）の再生と、音声のミックスも本番で。
