# 分析動画：読み上げの切れ目を、読み上げを呼ばずに直す（2026-10-09）

## 何を作ったか

- `evVizTts`：複数シーンをつないだ読み上げ（空行区切り）のときは、元の1本を `KT_TTS` の `ev:viz:full` に残す（`{blob, text, at}`）。
- 左パネルの操作部の下に「🎚 音声の切れ目」（`#ev-viz-cutbox`）。
  - 元の1本の台本（空行で分けたもの。話す速さの指示文は除く）と、各シーンに保存された音声の文を照らし合わせて、どのシーンの分かを決める。
  - 今の切れ目は、各シーンの音声の長さを足したもの。合計が元の1本と合わない（1シーンだけ作り直した等）ときは出さない。
  - 切れ目ごとに −0.5／−0.1／+0.1／+0.5 秒と ▶（前の2秒 → 0.4秒止める → 後ろの2秒）。
  - 「✂ この切れ目で切り直す」：元の1本を切って各シーンの音声（`ev:viz:nar:<id>`）と台本の秒数を入れ直し、部品を描き直す（部品は音声を最初に描くときに読むため）。

## なぜツール側に作ったか

- 本来は kessan-visualizer の `NarrationControls` / `audio/split.ts` の仕事だが、この日の作業環境は npm に出られず、部品（`assets/kessan-viz.js`）を作り直せなかった。
  ツールは音声の保存先（`evVizAudioStore`）と読み上げ（`evVizTts`）を部品に渡しているので、その2つを足場にツール側だけで完結させた。
- 部品に移すときは、`splitByScript` が切れ目（秒）を返すようにし、元の1本を `nar:_full` に残す形にする。
