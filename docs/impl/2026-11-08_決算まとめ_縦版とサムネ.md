# 決算まとめ：縦版（TikTok・インスタ）と、サムネの縦2段・中段の一文（2026-11-08）

Notion（📊 決算ツールPJタスク）：
- 「決算まとめ：縦版（1080×1920）を作れるようにする（TikTok・インスタ用）」
- 「決算まとめ：縦の2段サムネ（中段なし・改行あり）を出せるようにする」
- 「決算まとめ：横サムネの中段を銘柄名から「象徴する一文（6〜8文字）」にし、AI で作る」

YouTube は横版のまま。縦版は TikTok・インスタ用（すみぽん 2026-11-08）。

## 1. 縦版の動画（部品 kessan-visualizer）

- `DigestSettings` に `orientation`（landscape／portrait）を足し、`withDigestOrientation(s, o)` で幅・高さも切り替える。保存の形は `dg-settings` の JSON に入るだけなので、ツール側の保存は変えていない。
- `itemSettings` は各銘柄の settings をまとめの向きに合わせる（前は landscape 固定）。各銘柄の本編（Main）は 13 シーンとも縦の描き方（PORTRAIT_AREA）が元からあるので、そのまま。
- 読み上げ音声はシーン id ごと（`ev:viz:nar:<scene>`）で向きに関係なく同じもの。効果音（チャイム）は部品に埋め込み、BGM は共通の 1 本。どれも横と同じ。
- 表紙・つなぎ（`Board`）：`usePortrait()` で `BoardPortrait`／`BoardLandscape` に分けた。縦は「決算まとめ＋日付」→「本日のラインアップ」→ カードを 1 列（枠に入る高さまで縮める）。つなぎでは下に note の帯（左 QR・右 文）。横は変えていない。
- 最後（`OutroScene`）：縦は見出し → QR を中央に大きく → 下に帯。
- パネル（`DigestPanel`）：「向き」の切り替え（横 1920×1080（YouTube）／縦 1080×1920（TikTok・インスタ））。MP4 のファイル名は縦なら `digest_<日付>_縦.mp4`。

## 2. サムネ（ツール index.html・`#dg-thbox`）

- **横（3段）の中段**：「中段の一文（横）」の欄 `dg-th-key`。入っていればそれ、空なら今までどおり銘柄名の列。
  - 「✨ API で作る」（`dgThKeyGen`）：各銘柄の一言（headline）・判定・株価の動き（表紙のカードの下の行）を渡して、6〜8 文字の一文を 3 案。1 案目を欄に入れ、ほかは右の選択から。モデルは ⚙ 設定 › 決算まとめ「サムネの一文のモデル」（`dg-model`。空＝Gemini を上位から）。呼び出しは `callGeminiAnalyze`（aiFetch 経由で画面から直接）。
- **縦（2段）**（すみぽん 2026-11-08）：上段「11月8日（白）」「注目銘柄（黄色）」の 2 行、下段「図解で」「決算解説」の 2 行。ラベル（左上の丸帯）は無し。部品は決算分析の 2 段サムネと同じ `buildVThumb2(…, p2)`（`dgTh2Parts` で文を作る。日付は横の 1 段目の文から）。中段の一文は縦には使わない。
  - プレビューは横の右に並べて出す（`dgThPreview`）。「💾 縦PNG」は `renderVideoToBlob({thumb:true})`（1080×1920）。
- 保存の直し：`TAB_IO.digest.roots` に `#dg-thbox` を足した。右側のサムネの欄は保存の範囲（`#mode-digest`）の外にあり、サムネの文が PJ に残っていなかった。

## 同日の直し（レビュー：8 銘柄で下が切れる・「概要欄」）

- 縦のつなぎで 8 銘柄のとき、カードの最低の高さを 110px に決め打ちしていて note の帯の下に隠れた。見出しの下の空きを詰め（カードの上端 430→290、note の帯 520→440）、最低の高さを決め打ちせず枠に収まるまで縮める（字も合わせて縮める）。8 銘柄で確認。
- 縦は TikTok・インスタ向けで「概要欄」が無いので、つなぎの帯と最後の帯の文を「プロフィールのリンクからも」に変えた（キャプションのリンクは押せないので、プロフィールに置く前提）。横は「概要欄」のまま。
- 読み上げ（最後の文）は横と同じ音声を使うので「概要欄のリンクから」と言う。縦だけ別の文にするかは未決。
- 2 回目のレビュー（縦の構成を考え直す）：つなぎの帯は文を左（note の札＋「銘柄分析を／公開中」）・QR を右にし、「QRから記事一覧へ」は QR の真下。下の行（リンクの案内）は置かない。最後は下の帯をやめ、見出し・説明・QR・「QRコードから記事一覧へ」をひとまとまりで上下の中央に。横は変えていない。

- 3 回目のレビュー：
  - 縦用の最後の文 `outro_v`（読み上げは `nar:outro_v` → ツールでは `dg:nar:outro_v`）。横の文の「概要欄」を「プロフィール」にしたものを自動で入れ、手で直していなければ横の文に追従（`outro_v_auto`）。縦で縦用の文があればそれを使う（`outroPart`）。読み上げは「冒頭と最後（横・縦）の音声を作る（読み上げ1回）」で 3 つをつないで 1 回だけ呼び、切り分けて保存（縦用が空なら 2 つ）。回数は増えない。
  - つなぎの帯：「銘柄分析を公開中」を 1 行、その下に「リンクはプロフィールからも ▶」、QR の下は「記事一覧はこちら」。最後の画面にも「リンクはプロフィールからも ▶」の帯を QR の下に（まとまりの一部として中央寄せ）。
  - 縦 2 段サムネ（`buildVThumb2`）：ラベルが無いとき（決算まとめ）は上段：下段＝5：5 にし、上段の字も 3:4 の上端から中央に置く（前はラベルの分だけ下に詰めていた）。決算分析（ラベルあり）は変わらない。
