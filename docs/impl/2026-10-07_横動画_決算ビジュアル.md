# 横動画（決算ビジュアル）を決算分析タブに組み込む（2026-10-07）

Notion: 「決算分析タブに「横動画（決算ビジュアル）」を組み込む」（📊 決算ツールPJタスク）。
本体は別リポジトリ `C:\work\kessan-visualizer`（設計書 `docs/design/2026-10-06_MVP設計書.md`）。

## 何を作ったか

- 決算分析タブに3つ目のサブタブ **📽 横動画** を追加（左 `#earn-tab-viz`、右ペイン `#earn-viz-view`）。`switchEarnTab` / `earnPrevMode` に `viz` を追加。
- 左パネル：モデル選択（`#ev-viz-model`）、「🎬 Gemini で動画データを作る」、状態表示、「📤 出力データ作成のあとに自動で作る」チェック（`#ev-viz-auto`、既定オン）、手動経路（プロンプトをコピー → ChatGPT などに PDF と貼る → 結果を貼り付け → 検証して読み込む）、MP4用データ／JSON のダウンロード、消す。
- 右ペイン：kessan-visualizer の埋め込みバンドル `https://kessan-visualizer-0qcdd7p452hdo2tqpjogkqyghztjg7qqdoqvrsgc.pages.dev/embed/kessan-viz.js`（React 込み・約 700KB）を **必要になったときだけ** `<script>` で読み、`window.KessanViz.mount()` で 1920×1080 のプレビュー（Remotion Player）とシーンのチップ（表示／秒数／順番）、書き出しボタンを描く。
- データは `#ev-viz-json`（`{analysis, visualization, source, created}`）と `#ev-viz-settings` に入れる。どちらも `#mode-earnings` の中の textarea なので、`TAB_IO` 経由で PJ と一緒に D1 へ保存され、PJ を切り替えると右ペインも描き直す（`evVizMount` が JSON の変化を見る）。
- `geminiFormatEarn` の末尾で、チェックがオンなら `evVizGenerate(null,{quiet:true})` を呼ぶ。添付済みの決算 PDF（`window._earnFiles`）をそのまま Gemini に渡し、`KessanViz.prompt()`（JSON Schema 入り、約1.7万字）で財務 JSON を抽出 → `KessanViz.parse()`（表記ゆれ吸収 → Zod 検証）→ `KessanViz.build()`（評価・注目点・表示用 JSON）→ 保存。
- 関数はすべて接頭辞 `evViz`。本体スクリプトの末尾にまとめて置いた。

## なぜそうしたか

- 「別ツールへ飛ばしたくない」（すみぽん）。Remotion は React なので、kessan-tool（素の HTML）には React 込みのバンドルを外から読む形がいちばん小さい変更。
- 既存の整形プロンプトに JSON Schema を足す（1回の呼び出しで両方出す）案は、既存出力の品質が落ちるリスクがあるので採らず、**ボタン1つで Gemini を2回**（整形 → 横動画データ）にした。無料枠の 20回/日 を2回分使う点はチェックで切れる。
- 財務計算・評価・図の描き方はすべて kessan-visualizer 側にある。kessan-tool 側は「PDF を渡す・保存する・描かせる」だけ。直すときは kessan-visualizer を直して push すれば、kessan-tool は読み直すだけで反映される（URL に時刻のクエリを付けて1時間ごとに取り直す）。

## 確かめたこと

- `node --check`（2つの `<script>` ブロック）通過。
- ローカル（`wrangler pages dev . --port 8799`）で、📽 横動画 タブ → 手動経路にダミー JSON（Metric を数値だけで書いた省略形）を貼る → 右ペインに Player・警告（出典なし）・シーンのチップ・書き出しボタンが出ることを確認。
- Gemini 経路は本番の `GEMINI_API_KEY`（kessan-tool は設定済み）で動く想定。実 PDF での抽出精度は未確認。

## 残り

- 実際の決算 PDF で「🎬 Gemini で動画データを作る」を試し、プロンプト・正規化を kessan-visualizer 側で調整。
- MP4 書き出しはローカル専用（`kessan-visualizer` で `npm run render -- <MP4用データ.json>`）。ナレスラ連携は後回し（1分超の動画は差し込めないため）。
- 横動画を1本の投稿用動画にするには音声・導入が別途必要。

## 追記（同日）NIKE 実データのレビュー対応

- 右ペインの「MP4 を書き出す」で**ブラウザだけで MP4 を作れる**ようにした（kessan-visualizer 側の部品。1920×1080・30fps・H.264、70秒の動画で2〜3分。タブを表示したままにする。隠すと一時停止）。左パネルの案内文も差し替え。
- 保存してある抽出データ（analysis）があれば、表示のたびに最新の変換ロジックで visualization を作り直す（`evVizMount`）。表示の改善（単位・ラベル・総括の整理）が既存の PJ にも効く。
- 通貨（ドル建て）、文字切れ、セグメント説明、総括の余白は kessan-visualizer 側で対応。NIKE の PJ は Gemini で作り直すと「億ドル」表記・日本語のセグメント名になる（既存データは通貨情報が無いため円表記のまま）。
- 右ペインの下にあったシーンのチップ・書き出しボタンは見えにくいため、左パネル（`#ev-viz-controls`）に移した（埋め込みの `controlsEl`）。
