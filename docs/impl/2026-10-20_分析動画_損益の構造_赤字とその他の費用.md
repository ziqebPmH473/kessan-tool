# 分析動画：損益の構造（赤字・研究開発費など）を正しく描く（2026-10-20）

すみぽん：「決算の分析動画で、損益の構造のグラフおかしくない？SPCXのやつ確認して」。

SPCX の PJ の中身（本番 D1）はこの作業環境から読めなかったので、SpaceX の 2Q（売上 78.1億ドル・営業損失 1.4億ドル）に近い数字で再現して確かめた。

## おかしかった所（kessan-visualizer）

1. **営業赤字だと営業利益の棒が消える**。棒は「地面（0）から上」しか描けず、マイナスの高さは 0 になっていた。数字だけが地面の線の上に浮く。
2. **引き算が営業利益に届かない**。グラフは 売上高 − 売上原価 − 販管費 ＝ 営業利益 のつもりだが、米国基準は研究開発費などが販管費と別の行なので、販管費まで引いても営業利益にならない（SPCX 風の数字だと 23.1 と −1.4 の間の 24.5 が説明なしに抜ける）。IFRS の「その他の収益・費用」も同じ。
3. 営業利益率がマイナスでも緑で出ていた。

## 直したこと（visualizer ee645f0・ブランチ ccr-3ef03b12-ud9xv1）

- `src/analysis/build.ts`：営業利益の手前までの引き算と営業利益の差が売上の 0.5% を超えたら、差を1本の棒にして営業利益の前に入れる。費用側なら「− その他の費用」（引く項目が1つも無いときは「− 費用」）、収益側なら「＋ その他の収益」。
- `src/schema/visualization.ts`：損益の棒の種類に `plus`（足す項目）を追加。
- `src/remotion/scenes/PlWaterfallScene.tsx`：棒を「from → to の高さ」で描くようにし、0 を下回るときは 0 の線を上げてその下に描く（赤字の小計は赤・数字は棒の下）。営業利益率がマイナスなら赤。
- ふつうの黒字の会社（ダミー）は前と同じ絵になることを確認。

## 確かめたこと

- `npm run typecheck`、`scripts/selfcheck.ts`。
- `remotion still` で 4 通りの PNG：SPCX 風（その他の費用＋営業赤字）、ふつうの黒字、その他の収益あり、売上と営業利益しか無い（「− 費用」1本）。
- 既存の PJ にも表示のたびに効く（動画データは表示のたびに作り直す）。台本の固定文「売上高から売上原価と販管費を引いた利益の構造です。」はそのまま。
