## 経緯（試作した順）

| 版 | 中身 | すみぽんの反応 → 次にしたこと |
|---|---|---|
| 1本目 `Sample` | 暗い紺の背景、厚みを重ねた立体文字、積み木・水槽・着地で揺れる | 「安っぽい」→ 原因は色（暗い背景＋派手な色）・文字（ワードアート風）・影のない質感、いまの動画（白地）との不一致 |
| 2本目 `Sample2`（横） | いまの分析動画の白地・配色のまま、いまのグラフを立体にして白いスタジオで撮る。やわらかい影 | 「見え方は悪くない。業績の推移の見せ方はいい」。ただし強調の場所とカメラワークに問題 |
| 3本目 `ShortWater`（縦） | 超ショート。売上の水が原価・販管費へ流れ、残りが利益 | 「楽しむのが目的ではなく、今回の決算がどうだったかが見てわかるのが目的。売上から残る利益だけを切り取る必要はない」 |
| 4本目 `ShortResult`（縦） | 結果（推移の中の今回）・理由・この先の3つ＋まとめ | 方向は悪くない → 「部品を全部作っておき、主役／さらっと／使わないを決算ごとに選ぶ。選ぶのはAI（分析の中で）」 |
| 5本目 `Parts-*`（縦20秒） | 部品を選んで組む形。いまの形 | 以下の指摘で部品を直してきた |

5本目に入ってからの指摘と対応：
- 事業ごとの増減を前年の利益に積む図はおかしい（積み上げは売上→利益の構造の話）→ 事業ごとは立体の円グラフ（注目の事業が持ち上がる）、積み上げは「売上→利益の構造（pl）」だけに使う。
- 株価と決算ハイライトは必要 → ハイライトは毎回、株価も毎回（主役かさらっとかはAIが選ぶ）。
- ハイライトも3Dに。秒数の割合を変える。pl はハイライトと重なるので選び方から外す（部品は残す）。
- 「元の動画にも使えそう。省いた場面も全部作り、3Dと選べるように」→ 予想の修正・四半期単独・貸借対照表・キャッシュフロー・注目ポイントを部品にした。
- ハイライトで数字が違うのに高さが同じ → 4つとも同じ尺度に。
- 予想の修正は、元の数字が新しい数字に変わり、差が見えるのがいい → 項目ごとに棒1本で、修正前→修正後へカウントし、差の分に色。修正前の高さの線（蓋）は不要とのことで外した。
- 会社予想は利益だけではない（売上も。片方だけ・向きが違う修正もある）／推移と来期予想を利益だけにする意味がない → 推移は売上と営業利益を同じ尺度で、来期予想と予想の修正は売上・利益の両方を出す。

## いまの形（`samples/3d-sample/src/v5/`）

- `types.ts`：材料（`ShortData`。分析データから機械的に作る想定）と選び方（`ShortPlan`。AIが出す想定）。
- `Short.tsx`：20秒の組み立て。冒頭の札1.5秒 → 決算ハイライト3.2秒（毎回）→ 主役（残りの時間。さらっと2つなら約8.2秒）→ さらっと 各2.4秒 → まとめ2.2秒。
- `registry.ts`：AIが選べる部品の一覧。部品はどれも「主役版」と「さらっと版」を持つ。
  - `parts.tsx`：事業ごとの売上（円グラフ）・売上→利益の構造・数字以外・株価・（平面のハイライト）
  - `parts2.tsx`：決算ハイライト（3D）・貸借対照表・キャッシュフロー・四半期単独・注目ポイント
  - `parts3.tsx`：業績の推移（赤字転落も同じ部品）・来期の予想・予想の修正（言葉の出し分けは `revisionWord`）
- `examples.ts`：伸びた会社・赤字の会社の材料と、選び方の例3つ。**選び方は人が書いた想定の値で、AIにはまだ出させていない**（この作業環境にAIのキーが無かった）。
- `Catalog.tsx`：全部の部品を主役版→さらっと版で並べて見るカタログ。

## 決めたこと・理由

- 見た目は白地・いまの分析動画の配色・すっきりした文字。高級感は光と影（やわらかい影）で出す。飾った立体文字は使わない。
- カメラは場面ごとにほぼ固定。投資の動画で数字を読ませるには、動き続けるカメラは邪魔。楽しさは「数字の意味どおりに物が動く」ことで出す。
- 強調は色（主役以外をうすく）でつける。
- マイナスの値は0の線（うすい板）を持ち上げて、下へ伸ばす。0の線の高さはいちばん深いマイナスに合わせる。
- 決算ハイライト・業績の推移は、全部同じ尺度。来期の予想・予想の修正は、売上と利益で枠を分け、枠の中だけ同じ尺度（同じ尺度だと利益の変化がほぼ見えないため）。→ すみぽんの判断待ち。

## すみぽんの指摘の一覧（試作の会話から、時系列順）

### 方向性・目的
1. 投資系の動画で、もしも系3D動画の見せ方をもっと活かせないか。
2. 構成は別として、もしも系の見せ方は見入ってしまう。取り入れれば視聴維持率が上がり、フォロワーも増えるのではないか。
3. 「もしも」というお題は投資には合わない。
4. 数字を身近な物に置き換える案（札束を積む・1秒あたりの売上など）は、いまの視聴者から外れる。いまの動画を視覚的に楽しく見られるものがいい。東証マーケット振り返りのツールも同じ。
5. 結論は冒頭で言っているし、書いてもいる。ただ、視覚的ではなく、楽しくはない。
6. 楽しむのが目的ではない。今回の決算がどうだったかが視覚的に分かるのが目的。

### 見た目
7. 1本目は安っぽい。色合いか、文字か。
8. もしも系の見せ方は3Dの要素が強いのでは。積み木にする必要はない。
9. 2本目（白地の3D）は、見え方は悪くない。業績の推移のグラフの見せ方はいい。
10. ただし、強調すべき場所がおかしい。カメラワークにも問題がある。
11. 投資の動画で、カメラワークを変える必要はあるのか。

### 超ショートの組み方
12. 超ショートとして、決算の数字を視覚的に表す動画を別に作るのはありかも。茶化さず、細かい解説は本編へ流すイメージ。
13. 売上からいくら利益が残ったかは大事だが、それだけを切り取る必要があるのか（「強調すべき場所がおかしい」の意図）。
14. 4本目は、方向としては悪くない（細かい指摘はあるが、あとで）。
15. 部品は全部作っておいて、決算ごとに注目すべき部品を主役に描き、それ以外はさらっと動かす。主役・さらっと・使わない、をその都度決める。
16. 超ショートは20秒くらいでもいい。20秒で決算が分かれば嬉しい。
17. 選ぶのはAI。分析の中で選ばせる。
18. 株価と決算ハイライトは必要。
19. 秒数の割合は変えたい。
20. 売上→利益の構造は、決算ハイライトがあるので無くてもいい（部品は消さない）。

### 部品ごとの中身
21. 事業は、前年の利益に積み上げるものではない。事業ごとの割合は円グラフ。積み上げるのは売上→利益の構造。
22. 決算ハイライトも3Dにしたら。
23. 決算ハイライトで、数字が違うのに高さが同じなのはおかしい。
24. 業績修正は、元の数字が消えて新しい数字に変わり、かつ差が見えるのがいい。
25. 会社予想は利益だけではない。売上も利益も修正、片方だけ修正、両方修正で向きが違う、などがある。
26. そもそも下方修正ばかりではない。
27. 推移も来期との比較も、利益だけにする意味が分からない。
28. 修正のときの蓋のようなもの（修正前の高さの線）は要らない。

### 本編への展開
29. これはそのまま元の動画（分析動画）にも使えそう。省いた場面は全部作ってほしい。全部作って、3Dと選べるようにするのがいい。

### 保留
- 効果音は必要。ただし、まず見た目と見せ方から。
- 4本目以降の細かい指摘は、あとでまとめて（14番）。
- 円グラフ・業績の推移・来期の予想など「概ねよい」とした部品の細部。

### 組み込み後の指摘（2026-11-27 夜。kessan-visualizer に「3D（試し）」を入れたあと）
30. 3D にしたら安っぽくなった。試作で見ていたものより安っぽい（背景が白・床の境目・透かしが3Dの上、が原因）。
31. 元のほうが見やすい。見づらくなっただけ。
32. 同じ数字は同じ長さでないとグラフの意味がない（売上と利益で枠を分けて尺度を変えたのは誤り。25・27番の「枠分け」は同じ尺度にする）。
33. 元の配置を変えない。
34. 項目名・見出しが正面を向いていないので読めない（床に寝かせた文字）。
35. 数字でないもの（5段階の評価など）を棒グラフにしない。
36. チャート（株価を3Dの線にしたもの）がいちばん微妙。
37. 粗利率と営業利益率だけを並べた棒の意味が分からない。見出しが営業利益率の変化だけなのも、グラフで分かる前年・今年の数字を見出しにくり返すのも意味が分からない。

39. 試作で見せていたものから形式が変わっている（2本目の推移には営業利益率の線があった。組み込んだのは5本目＝ショート用の部品だった）。
