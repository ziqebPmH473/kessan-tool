# 決算カレンダー（2026-09-25）

上の段の「📅 決算カレンダー」で、日本株・米国株の決算発表の予定日を月カレンダーで見る。マネックスの決算カレンダーの形（2か月並べて日ごとの件数 → 日付を押すとその日の一覧、コード・企業名で絞り込み）。全件表示。

## 作り
- 画面：`index.html` の `#kc-view`（画面いっぱいに重ねる）と `kc*` の関数。**PJ・DB保存とは切り離している**（種別のプルダウンには入れていない。保存の門や KTStore に触れない）。国内／米国の選択だけ localStorage `kc-mk`。
- サーバ：`functions/api/calendar.js`。結果を Cloudflare のキャッシュに 6 時間置く。

## 取り先
| 市場 | 取り先 | 呼び方 |
|---|---|---|
| 米国 | Nasdaq の決算カレンダー（`api.nasdaq.com/api/calendar/earnings?date=`。公開された窓口ではない） | `?market=us&month=YYYY-MM`。その月の平日を1日ずつ（最大23回） |
| 日本 | JPX「決算発表予定日」の Excel（ページにある xlsx を全部） | `?market=jp&src=jpx` |
| 日本 | 日経「決算発表スケジュール」（月ごと、50件ずつのページ） | `?market=jp&month=YYYY-MM&hm=1`。最大40ページずつ、残りは `next` |

- **なぜ日経も使うか**：JPX は 3月期・9月期の会社（大企業の多く）を「翌営業日の分」しか載せない。日経は会社が発表日を決めた時点で載る。
- 同じ会社が両方にあるときは JPX を優先（45日以内に JPX の行があれば日経の行は捨てる）。
- xlsx は Workers 上で自前で読む（zip の中央ディレクトリ → `DecompressionStream('deflate-raw')` → sharedStrings と sheet1 を正規表現で）。
- 1実行 50 回の外部取得の上限：キャッシュは月ごとに1つにまとめているので、米国は最大 23＋キャッシュ2 回。

## 気をつけること
- Nasdaq・日経はページや窓口の形が変わると読めなくなる。画面の情報元の行に赤字で「読めませんでした」「読めなかった日」が出る。
- 行の銘柄コード・ティッカーは株探へのリンク。
