# 株価分析：ブログ用 ZIP にスライドの画像を入れる（2026-11-03）

依頼：株価分析「記事・SNS」の「💾 ブログ用 ZIP」に、スライドの画像が入っていなかった → 入れる。
Notion：決算ツールPJタスク「株価分析：ブログ用 ZIP にスライドの画像を入れる」

## 作り（`index.html` の `saBlogSlides` → `saBlogZip`）

- note の本文には、記事プロンプトの段階で画像の枠 `[ここに「…」のスライド画像を挿入]` が見出し 1〜5・まとめの下に、`[ここに「ご注意」の画像を挿入]` が末尾に入っている。
- スライド作成タブの6枚（01 現状整理・02 短期予測・03 12か月シナリオ・04 転換点・05 リスク・06 まとめ）は、記事の見出し 1〜5・まとめに1対1で対応する。枠の行の直前の見出し（`## 1`〜`## 5`・`## まとめ`）でどのスライドかを決め、「ご注意」は固定画像 `assets/disclaimer_note.png`。
- ブログのコンソール（sumikko-money の docs/article-zip.md）は画像をファイル名の順に枠へ上から入れるので、本文の枠の順に `画像/01_….png` と名前を付ける。見出しが分からない枠・同じスライドの2つ目の枠は、行ごと外して枠と画像の数をそろえる。
- スライドの画像化は、スライド作成タブの「全部ダウンロード」と同じ `renderToBlob`（1280×720 を2倍で PNG）。
- スライドデータ（ta-data）が空のときは画像なし・枠はそのまま（あとからコンソールの画像の欄に落とせる）。
