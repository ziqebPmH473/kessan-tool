# 決算分析：出力データ作成＋分析動画データを ChatGPT で一括（2026-10-08）

API（Gemini）が混んでいるときの手動ルート。「📤 出力データ作成」の下の「手動で作る（ChatGPT など。APIが混んでいるとき）」。

- 「💬 プロンプトをコピー」（`earnManualCopy`）：プロンプトのコピーと、添付ZIP `<コード>_<銘柄名>_ChatGPT添付.zip` の保存を同時に行う。
  - ZIP の中身：`株探取得データ.txt`（`getEarnSourceText`）、`分析レポート.md`（FCレポート貼付欄）、決算資料（添付欄のファイルをそのまま）。
  - プロンプト（`earnManualPrompt`）：ZIP の中身の説明 ＋ API と同じ `buildEarnNBPrompt()` ＋ `GROUNDING_RULE` ＋ `evVizJoinPrompt`。違いは1点だけ：[CHART_DATA] の data= は空欄にさせる（日足を全部書かせると答えが長すぎるため。展開時に `complementEarnData` が株探の値で埋める）。
- 「📋 貼り付けて展開」／「✅ 欄の内容で展開」（`earnManualApply`）：`evVizSplitResponse` でテキストと json に分け、テキストは [HEADER] から後ろを 2. の欄へ（前置きの文・囲みのコードブロックは外す）→ 株探の値で補完 → 画像。json は `KV.parse` → `evVizCommit`。形式に合わなければ分析動画タブの手動欄に入れて知らせる。最後に API と同じく JSON を書き出す。
- 動画（台本・縦スライド・投稿文）の自動生成（ev-auto）は、手動ルートでは走らせない（Gemini API を使うため）。
