# 注目銘柄（🔥 注目）— 2026-11-03

## 何を作ったか
- 上のバーの「🔥 注目」で、株サイトのランキングを集めて「いま注目の日本株」を点数順に並べる全画面を開く（決算カレンダーと同じ作り。PJには入らない）。
- どの銘柄を分析するか迷ったとき、候補を入れずに使う。X など SNS は API が有料なので入れていない。

## どこで作っているか
- サーバ側：`functions/api/hot-stocks.js`（AIは使わない。取得とパースだけ。結果は Cloudflare のキャッシュに 1 時間。`?fresh=1` で読み直し）
- 画面側：`index.html` の `hsOpen / hsLoad / hsRender`（`kcClose` のすぐ下）、HTML は `#hs-view`（`#kc-view` の下）、CSS は `.hs-*`

## 集める元と重み（1位がもらう点。下にいくほど減る）
| 元 | 重み | 備考 |

| 株探 本日の活況銘柄（売買代金、3ページ45件） | 30 | Yahoo と重なるので、売買代金が大きい銘柄は両方で点が入る |
| 株探 動意株ニュース（2ページ） | 25 | |
| 株探 ストップ高 | 20 | |
| 株探 決算発表（取引終了後2ページ＋取引時間中1ページ） | 25 | 決算ポイントの文を「材料」に出す |
| 株探 人気の株式テーマ（3日間）の関連銘柄3つ | 20 | テーマの順位をそのまま使う。TOPIX・JPX日経400・読売333 など指数のテーマは外す |
| みんかぶ 買い予想数上昇（20件） | 25 | |
| みんかぶ 人気テーマの代表銘柄 | 15 | |
| 株探 人気ニュース（直近8時間） | 20 | 見出しに、集まった銘柄名（3文字以上）が入っていたら足す |

- ETF・上場投信は外す。
- 読めなかった元は `failed` に入れて残りで返し、キャッシュには置かない。画面にも赤字で出す。

## 使えなかった元
- Yahoo!ファイナンス「今注目（閲覧者数）」は有料会員向けで中身が取れない。掲示板の投稿数ランキングも URL が見つからなかった。
- みんかぶのアクセスランキングも URL が見つからなかった（買い予想・テーマで代用）。
