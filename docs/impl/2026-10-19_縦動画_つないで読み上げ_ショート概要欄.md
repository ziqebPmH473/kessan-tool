# 縦動画：台本をつないで読み上げ・文字起こしで切り分け／速さ・作り直し／YouTubeショートの概要欄（2026-10-19）

対象：株価分析の縦動画（vd）。音声の関数は決算分析の縦動画（ev）と共用なので、音声まわりは両方に効く。
Notion：決算ツールPJタスク（5件。「株価分析の縦動画：…」で始まるもの）

## 1. つないで読み上げ → スライドごとに切り分け（a044e7d）

- `vdGenAllTts(P,btn,redo)`：音声が無い・台本が変わったスライドの台本を空行でつなぎ、1回が約1分（`VD_ONE_MINUTE_CHARS`=420文字）以内になる数（`VD_TTS_MAX_CALLS`=2 まで）に分けて `/api/tts` を呼ぶ。1枚だけなら今までどおり `vdGenTts`。
- `vdSplitByScript(blob,texts)`：kessan-visualizer の `src/audio/split.ts` の移植。確実な順に
  1. 文字起こし（`/api/transcribe`、Whisper の語の時刻）と台本を1文字ずつ照合（`vdAlignChars`／`vdAlignBounds`）、各スライドの読み始めの手前の無音で切る
  2. 長い無音（0.18秒以上）の上位 N-1 個
  3. 文字数の割合で見当をつけ、近く（±3秒）の無音
  読み上げは呼び直さない（上限対策）。どのやり方で切ったかは状況欄に「切れ目：文字起こし」のように出す。
- 保存の形は前と同じ `{b64, seconds, voice, model, text}` に `speed`・`method` を足しただけ。結合（`vdConcatWavs`）・書き出し（`.svpz`）はそのまま。
- 上限（429 など）に当たったら止めて知らせる。できた分は保存済み。

## 2. 速さ・声・モデルの置き場・全部作り直す（03ee28d）

- 声・モデルの行を設定タブの隠し欄（`kg-hide`）から「台本・音声」タブの音声化ボタンの上へ。値は全PJ共通のまま（変えると `vdTtsSetCommon` → `kgSet`）。
- 速さ `vd-tts-speed`／`ev-tts-speed`（共通設定 `tts-speed`、初期値「ふつう」＝今までと同じ音）。読み上げの頭に分析動画と同じ `VD_SPEED_HINT` を付ける（台本の保存・文字起こしの照合には入れない）。
- 「🔄 全部作り直す」＝ `vdGenAllTts(P,btn,true)`。

## 3. YouTubeショートのタイトル・概要欄（株価分析だけ）

- プロンプト `VIDEO_PROMPT_VD` に 10 ブロック目「【YouTubeショート】」（タイトル・説明・タグ の3行）。`parseVideoOutput` のキー `yt`。SNS再生成（`geminiVideoSns`）でも 7〜10 を出させる。
- `vdYtCompose`：タイトル＝【銘柄名（証券コード）】＋AIの問いかけ。概要欄＝問いかけ → 説明2文 → まとめスライドの問い（[V5] 問い）→ note案内文（xnote）→ ▼ note の URL（`ytNoteUrl()`、空なら省く）→ 定型文（共通設定「縦動画の概要欄の定型文」`vd-yt-fixed`）→ ハッシュタグ（AIのタグ＋固定タグ）。
- AIの3行は `vd-yt-ai`（非表示）に控え、「🔄 組み直す」で URL・定型文を入れ替えて組み直せる。

## 確認したこと

- ローカル（wrangler pages dev）で、合成音声の切り分け（無音／文字数の見当）と概要欄の組み立てを確認。文字起こし・実際の読み上げは本番で要確認。

## 4. 画面を「動画｜SNS｜データ」に組み直し・速さの初期値（同日・追記）

- タブ：動画（動画の設定＝サムネ文（決算分析）・QR用URL・枚数（決算分析）・チャート期間・透かしロゴ・サムネを動画の頭に入れる ＋ 台本と音声）｜SNS（投稿文。ショートURLは YouTube の概要欄の下）｜データ（スライド用データ・.svpz の書き出し・生成全文・隠し欄）。`vdInnerTab` のキーは video/sns/data。
- 読み上げの速さの初期値を「速め」に。すでに「ふつう」が入っている端末は、`kgApply` で1回だけ「速め」に置き換える（`_vdSpeedFaster`）。
