# 3D演出のサンプル動画（試作）

「もしも系3D動画」の見せ方を、決算の解説に入れたらどう見えるかの試作。ツール本体（index.html / kessan-viz.js）とは無関係。
数値はすべて架空（サンプル株式会社）。

使ったもの：Remotion ＋ Three.js（@remotion/three）。分析動画（kessan-visualizer）と同じ土台。

| 場面 | ファイル | 取り入れた見せ方 |
|---|---|---|
| 冒頭（5秒） | `src/Hook.tsx` | 結果を先に見せる／立体文字＋数字だけ黄色／着地で画面が揺れる |
| 損益を水で（13秒） | `src/Water.tsx` | 売上の水が原価・販管費へ流れ出て、残りが利益。数字が動きながら増える |
| 業績の推移（15秒） | `src/Stack.tsx` | 1年ずつ積む。年が進むほど速く積む（だんだん盛り上がる）。減益の年は上が落ちる |
| 予想の修正（8秒） | `src/Revision.tsx` | 上方修正の分が上から落ちてきて、最後に大きく揺れる |

## 動かし方（ローカル）

```
cd samples/3d-sample
npm install
npm run studio                                   # ブラウザで見ながら調整（左の一覧から動画を選ぶ）
npm run render -- Parts-Grow-Trend out/a.mp4     # 1本書き出す（名前は下の一覧）
```

- `npm run render` は `--gl=angle`（Windows／Mac でGPUを使う）。うまく描けないときは `--gl=swangle` に変えると遅いが確実。
- クラウドの作業環境（Linux）では `npm run render:cloud -- <名前> <出力>`。
- 書き出した動画（`out/`）と `node_modules/` はコミットしない。

## 2本目：いまの分析動画の見た目のまま3Dに（`src/v2/`、`npm run render2`）

1本目は「暗い背景・派手な色・飾った文字」で安っぽく見えたので、いまの分析動画（白地・青・緑・赤、すっきりした文字）に合わせた。
いまのグラフを、そのまま立体の物にして、白いスタジオでカメラで撮る形。

| 場面 | ファイル | 見せ方 |
|---|---|---|
| 冒頭（3秒） | `v2/Hook2.tsx` | いちばんの数字を先に。下から見上げて回り込む |
| 損益の構造（11秒） | `v2/Waterfall3D.tsx` | 売上の棒から、原価・販管費の分が抜け出して横へ移る。最後に営業利益へ寄る |
| 業績の推移（15秒） | `v2/Trend3D.tsx` | 棒が1年ずつ、だんだん速く伸びる。引いて全体 → 利益率の線が伸びる → 最後の2年へ寄る |

## 3本目：超ショート（縦）・売上の水（`src/v3/ShortWater.tsx`、`npm run short`）

本編の入口として、決算の数字を1つだけ見せる縦の短い動画（18秒）。白地で茶化さない。
売上の水が原価・販管費へ流れ出て、残りが営業利益。同じ底面積なので、水の高さ＝金額。カメラは動かさない。最後に「くわしい解説は本編で」。

## 4本目：超ショート（縦）・今回の決算がどうだったか（`src/v4/ShortResult.tsx`、`npm run short2`）

3本目は「売上からいくら残ったか」だけを切り取っていた。目的は「今回の決算がどうだったかが、見てわかる」なので、3つに分けた（30秒）。
① 結果：営業利益の推移の中で、今回の年だけ色を付ける ② 理由：前年の利益に、事業ごとの増えた分を積んで今年へ（主役の事業だけ濃い色） ③ この先：来期の会社予想（予想は薄い色）。最後に3行のまとめと本編への案内。
カメラは場面ごとに固定。強調は色（主役以外を薄く）でつける。

## 5本目：部品を選んで組む超ショート（`src/v5/`、20秒）

部品（推移・事業ごとの売上（円グラフ）・売上→利益の構造・会社予想・赤字転落・数字以外）ごとに「主役版」と「さらっと版」を用意し、
AIが出す選び方（`ShortPlan`：主役1つ・さらっと0〜2個・一言・まとめ3行）で 20秒の動画を自動で組む。
時間は「冒頭の結論 1.8秒 → 主役 → さらっと 各2.6秒 → まとめ 2.8秒」。主役の長さは残りの時間に合わせて伸び縮みする。
AIへの指示の案は `AI_PLAN.md`。

```
npx remotion render src/index.ts Parts-Grow-Trend out/Parts-Grow-Trend.mp4 --gl=swangle --browser-executable=/opt/pw-browsers/chromium_headless_shell
```
（Parts-Grow-Seg、Parts-Loss も同じ）

※ 最初は「前年の利益に事業ごとの増減を積む」図にしていたが、損益の構造と同じ見た目で意味が違い混乱するのでやめた。事業ごとは円グラフ、積み上げは売上→利益の構造だけに使う。

※ 決算ハイライト（毎回、冒頭の札のすぐ後）と株価の反応（毎回。主役かさらっとかはAIが選ぶ）を足した。20秒の割り振りは「冒頭1.8秒 → ハイライト2.4秒 → 主役約8秒 → さらっと 各2.4秒 → まとめ2.6秒」。

※ 決算ハイライトを3Dに（前年・今年の棒の組を4つ。数字ごとに高さの尺度は別）。秒数は「冒頭1.5 → ハイライト3.2 → 主役 約8.2 → さらっと 各2.4 → まとめ2.2」。
※ いまの分析動画から省いていた場面も部品にした：予想の修正（revision）・四半期単独（quarter）・貸借対照表（bs）・キャッシュフロー（cf）・注目ポイント（points）。
　全部の部品を主役版→さらっと版の順に並べた「部品カタログ」：`Catalog-Grow`（伸びた会社）、`Catalog-Loss`（赤字の会社）。部品の一覧は `src/v5/registry.ts`。

※ 業績の推移・赤字転落は売上と営業利益を同じ尺度で。来期の予想と予想の修正は売上・利益の両方を出し、売上と利益は枠を分ける（枠ごとに同じ尺度）。予想の修正の言葉は、項目ごとの向きの組み合わせで決める（`parts3.tsx` の revisionWord）。

## 実データで足りない部品を洗い出して足した（2026-11-27）

保存済みの決算PJ 99件の分析JSONを読み、部品で表せない場面・データの形を洗い出した。くわしくは `docs/impl/2026-11-27_超ショートの部品_実データで不足を足す.md`。

- 足した部品（`src/v5/parts4.tsx`）：通期予想への進み具合（progress）・5つの評価（ratings）・配当（dividend）・事業ごとの利益（segprofit）・利益率（margin）・営業利益から純利益まで（netgap）
- 直した部品：直近の3か月（quarter。データは「直近の1四半期だけ」なので、その形に）、業績の推移（会社予想の年をうすく）、会社予想（四半期の決算は「今期の予想」）、億ドル・小さい金額の小数、会社ごとの呼び名（売上収益・事業利益・親会社株主に帰属する〜）
- 分析JSON → 材料の変換：`src/v5/fromAnalysis.ts`。部品ごとの使える条件：`src/v5/availability.ts`
- 静止画で確かめる：`node stills.mjs <コンポジション名> <出力フォルダ> <コマ,…> [props.json]`。実データは `fromAnalysis` で変換した `{"data": …}` を props に渡す（実データの画像はコミットしない）

## 横の分析動画も3Dの部品で出す（2026-11-27）

いまの分析動画（kessan-visualizer）の13場面を、3Dの部品で組めるようにした。部品は縦（超ショート）と横（分析動画）の両方で使える。くわしくは `docs/impl/2026-11-27_超ショートの部品_実データで不足を足す.md` の後半。

- 横のときは左に文字の列、右に3D（カメラの写る範囲を右へずらす）。`Titles`・`Legend`・`Scene3D` が縦横を見分ける
- 足した場面：表紙・総括（`parts5.tsx`）。中身を足した場面：損益の構造（その他の収益・費用）、貸借対照表（内訳が前期末から今期末へ動く）、キャッシュフロー（換算差額など）、株価（取れた期間すべて）、注目ポイント（前後の数字）、予想の修正（理由）
- 実データで出すとき：`npx remotion render src/index.ts Video-Mid <出力.mp4> --props=<props.json> --gl=angle`（props は `{"data": fromAnalysis(分析JSON)}`）。書き出しはプロジェクトの外に置く
