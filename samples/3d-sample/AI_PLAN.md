# 超ショートの「選び方」をAIに出させる（案）

分析（kessan-visualizer の `prompt.ts` の分析JSON）に `short_plan` を1つ足す。材料（数字）は分析データから機械的に作るので、AIが選ぶのは「どれを主役にするか・どれをさらっと・何を一言で言うか」だけ。
型は `src/v5/types.ts` の `ShortPlan`。実際に動かした例は `src/v5/examples.ts`（3本とも人が書いた想定の値。AIにはまだ出させていない）。

## 決まって入るもの

- 冒頭の札と一言、**決算ハイライト**（売上・営業利益・経常利益・純利益を前年比つきで、3D。3.2秒）、まとめ3行。これはAIが選ばない。
- pl（売上→利益の構造）は、決算ハイライトと中身が重なるので、ふだんは選ばない（利益率そのものが話題のときだけ）。

## 部品（AIが選ぶ）

| id | 中身 | 使える条件 |
|---|---|---|
| trend | 業績の推移。売上と営業利益を同じ尺度で。主役は5年分を1年ずつ、さらっとは前年と今年 | trends が2期以上 |
| segments | 事業ごとの売上の割合（立体の円グラフ）。前年比がいちばん動いた事業が持ち上がって前に出る。下に割合・前年比の一覧 | セグメントが2つ以上 |
| pl | 売上→利益の構造。売上の棒から原価・販管費の分が抜け出し、営業利益が残る（赤字なら0の線の下へ） | 売上原価・販管費がある |
| forecast | 売上・営業利益・純利益の、今期の実績と来期の会社予想。売上と利益は枠を分ける（枠ごとに同じ尺度） | 会社予想がある |
| loss | trend と同じ部品で、赤字転落・黒字転換を言葉で強調（営業利益が0の線の下へ） | 今回か前年が営業赤字 |
| stock | 株価の反応。決算発表の前後の値動きの線、発表の日に印 | 株価のデータがある（毎回入れる） |
| revision | 会社予想の修正。売上・営業利益・経常利益・純利益ごとに棒1本で、修正前の数字が修正後に変わり、差の分に色（据え置きは灰色の札）。言葉は組み合わせで決まる：上方修正／下方修正／利益だけ上方修正／売上は上方・利益は下方 など | 今回、予想の修正がある |
| quarter | 3か月ごとの利益（四半期単独）を前年の同じ時期と並べる。直近の四半期を強調 | 四半期単独の数字がある（2Q以降） |
| bs | 貸借対照表。資産と「負債＋純資産」を並べ、自己資本比率を強調 | 貸借対照表がある |
| cf | キャッシュフロー。期首の現金 → 営業・投資・財務 → 期末の現金。自由に使えるお金（営業＋投資）を強調 | キャッシュフロー計算書がある（2Q・通期） |
| points | 注目ポイント（GOOD／WATCH の札） | ai_insights に positives／negatives がある |
| topic | 数字以外（増配・減配・自社株買い・M&A・工場の閉鎖など） | 資料に書かれている |

## プロンプトに足す指示（案）

- short_plan は、20秒の縦動画で「今回の決算がどうだったか」を伝えるための部品の選び方。
- main には、今回の決算でいちばん注目すべき点を表す部品を1つだけ選ぶ。key_drivers の1件目と同じ内容を表す部品にする。
  - 例：過去最高益・何年ぶりの増益 → trend ／ 特定の事業が伸びた・足を引っぱった → segments ／ 利益率の改善・悪化、原価や販管費の増減 → pl ／ 上方修正・下方修正 → revision ／ 直近の3か月で急に変わった → quarter ／ 財務の悪化・現金の減少 → bs・cf ／ 赤字転落・黒字転換 → loss ／ 予想の修正が主な話題 → forecast ／ 数字より増配・自社株買い・M&A が主な話題 → topic
- brief には、main を補う部品を0〜2個、見せる順に選ぶ。main と同じ部品は選ばない。使える条件を満たさない部品は選ばない。
- stock（株価）は毎回入れる。決算のあとに大きく動いたとき（目安：±5%以上）は main、そうでなければ brief に入れる。
- verdict は冒頭の札（増収増益・減収減益・増収減益・赤字転落・黒字転換・上方修正 など、6字以内）。headline は20字以内で、数字は書かない。
- captions は、部品ごとの一言（25字以内）。理由を書く。資料に書かれていない理由は書かない。
- summary は「結果・理由・この先」の3行（各15字以内）。売買の推奨は書かない。
