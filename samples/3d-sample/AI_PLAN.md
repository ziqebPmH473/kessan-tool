# 超ショートの「選び方」をAIに出させる（案）

分析（kessan-visualizer の `prompt.ts` の分析JSON）に `short_plan` を1つ足す。材料（数字）は分析データから機械的に作るので、AIが選ぶのは「どれを主役にするか・どれをさらっと・何を一言で言うか」だけ。
型は `src/v5/types.ts` の `ShortPlan`。実際に動かした例は `src/v5/examples.ts`（5本とも人が書いた想定の値。AIにはまだ出させていない）。
材料は `src/v5/fromAnalysis.ts` が分析JSON（決算PJの ev-viz-json）から作る。AIには、その会社で**使える部品だけ**（`availableParts`、条件は `src/v5/availability.ts`）を一覧で渡す。

## 決まって入るもの

- 冒頭の札と一言、**決算ハイライト**（売上・営業利益・経常利益・純利益を前年比つきで、3D。3.2秒）、まとめ3行。これはAIが選ばない。
- pl（売上→利益の構造）は、決算ハイライトと中身が重なるので、ふだんは選ばない（利益率そのものが話題のときだけ）。

## 部品（AIが選ぶ）

「件数」は、保存済みの決算PJ 99件（2026-11-27 時点）で使える件数。

| id | 中身 | 使える条件 | 件数 |
|---|---|---|---|
| trend | 業績の推移（通期）。売上と営業利益を同じ尺度で。会社予想の年はうすく。実績が1年だけなら、その年と今期の予想をくらべる | 2年以上（予想の年を含む） | 70 |
| loss | trend と同じ部品で、赤字転落・黒字転換を言葉で強調（営業利益が0の線の下へ） | 今回か前年が営業赤字 | 8 |
| segments | 事業ごとの売上の割合（立体の円グラフ）。前年比がいちばん動いた事業が持ち上がる。「地域ごと」「製品ごと」にも変わる | 2つ以上 | 85 |
| segprofit | 事業ごとの利益。前年と今年の棒の組、赤字の事業は0の線の下。利益がいちばん動いた事業を強調 | 事業ごとの利益が前年・今年とも2つ以上 | 56 |
| pl | 売上→利益の構造。売上の棒から原価・販管費の分が抜け出し、営業利益が残る | 売上原価・販管費がある | 91 |
| margin | 利益率（粗利率・営業利益率）を前年と今年で。今年の棒が前年の高さから動く | 売上と利益が前年・今年ともある | 94 |
| netgap | 営業利益 → 経常利益 → 税引前利益 → 純利益の段と、そのあいだの差（営業外・特別な損益・税金など） | 本業と最後の利益で、向きや黒字・赤字が食い違う | 10 |
| forecast | 会社予想。四半期の決算は「前期の実績と今期（通期）の予想」、通期の決算は「今期の実績と来期の予想」。売上と利益は枠を分ける | 会社予想がある | 67 |
| progress | 通期の会社予想に対する進み具合（%）。箱の高さ＝予想、中身＝ここまでの実績。時期の目安（1Q 25%・2Q 50%・3Q 75%）の線 | 1Q〜3Q の決算で、予想がある | 73 |
| revision | 会社予想の修正。項目ごとに棒1本で、修正前→修正後へ変わり、差の分に色（据え置きは灰色の札） | 修正前・修正後がある（据え置きを含む） | 78 |
| dividend | 1株あたりの配当の予想を、コインの山で（修正前→今回） | 配当予想が変わった（分割・中間と年間の取り違えのおそれがあるものは出さない） | 26 |
| quarter | 直近の3か月だけ（四半期単独）を、前年の同じ3か月と。決算ハイライトと同じ形 | 四半期単独の数字がある | 23 |
| bs | 貸借対照表。資産と「負債＋純資産」を並べ、自己資本比率を強調 | 合計が合っている | 94 |
| cf | キャッシュフロー。期首の現金 → 営業・投資・財務 → 期末の現金 | キャッシュフロー計算書がある | 76 |
| stock | 株価の反応。発表の前の40日と、発表の翌日 | 株価のデータがある（毎回入れる） | 98 |
| ratings | 5つの評価（成長性・収益性・財務の安全性・お金を生む力・資本効率）を柱の高さと色で | 評価がある | 97 |
| points | 注目ポイント（GOOD／WATCH の札） | 良い点・注意点がある | 99 |
| topic | 数字以外（増配・自社株買い・M&A・工場の閉鎖など） | 資料に書かれている | 97 |

## プロンプトに足す指示（案）

- short_plan は、20秒の縦動画で「今回の決算がどうだったか」を伝えるための部品の選び方。
- main には、今回の決算でいちばん注目すべき点を表す部品を1つだけ選ぶ。key_drivers の1件目と同じ内容を表す部品にする。
  - 例：過去最高益・何年ぶりの増益 → trend ／ 特定の事業が伸びた → segments、事業が利益を稼いだ・足を引っぱった → segprofit ／ 利益率の改善・悪化 → margin（原価や販管費の中身 → pl）／ 営業利益と純利益で向きがちがう・最終赤字 → netgap ／ 上方修正・下方修正 → revision ／ 予想に対して速い・遅い → progress ／ 直近の3か月で急に変わった → quarter ／ 増配・減配 → dividend ／ 財務の悪化・現金の減少 → bs・cf ／ 赤字転落・黒字転換 → loss ／ 来期・今期の予想が主な話題 → forecast ／ 数字より自社株買い・M&A が主な話題 → topic
- brief には、main を補う部品を0〜2個、見せる順に選ぶ。main と同じ部品は選ばない。使える条件を満たさない部品は選ばない。
- stock（株価）は毎回入れる。決算のあとに大きく動いたとき（目安：±5%以上）は main、そうでなければ brief に入れる。
- verdict は冒頭の札（増収増益・減収減益・増収減益・赤字転落・黒字転換・上方修正 など、6字以内）。headline は20字以内で、数字は書かない。
- captions は、部品ごとの一言（25字以内）。理由を書く。資料に書かれていない理由は書かない。
- summary は「結果・理由・この先」の3行（各15字以内）。売買の推奨は書かない。
